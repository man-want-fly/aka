# Code Conventions

- 仓库：AKA 单机行情工作台（macOS），Tauri 2 + Rust workspace + React/Vite。
- 后端 crate：`app/crates/{app-core,indicator-core,data-provider,data-store}`；命令注册在 `app/src-tauri`。
- 前端：`app/src`，类型集中在 `app/src/lib/types.ts`，IPC 唯一出口 `app/src/lib/ipc.ts`。
- 指标元数据唯一来源：`app/manifest/indicators.json`（前端只读它取默认参数，后端只读它做校验）。
- 错误码冻结在 §5 C-22：需求码 `E_PARAM_INVALID` ≡ 实现码 `E_PARAM_OUT_OF_RANGE`，不得新增/改名。
- 验证命令：后端 `cargo test -p app-core`；前端 `cd app && npx tsc --noEmit`。
- 注释与提交说明用中文；改动保持最小，不做顺手重构。
