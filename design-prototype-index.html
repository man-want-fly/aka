01公式

DIF = EMA(CLOSE, 12) − EMA(CLOSE, 26) DEA = EMA(DIF, 9) HIST = 2 × (DIF − DEA) ← A 股软件惯例，注意与国际实现差 2 倍 EMA_t = α·C_t + (1−α)·EMA_{t−1}, α = 2/(N+1) 种子：前 N 根用 SMA 作为首个 EMA 值（本产品固定此约定，不随数据源变化）

预热 34 根 = 26（慢线）+ 8（信号线收敛）。第 34 根起 DIF、DEA、HIST 才同时有效；不足时返回 NaN，由前端显示「需 34 根，当前 N 根」，不补 0、不画平线。

03怎么读

零轴上方金叉（DIF 上穿 DEA）比零轴下方金叉更可靠；A 股常见的「零轴二次金叉」是中期转强信号。柱状线由负转正只代表动能变化，不等于价格反转——连续涨停时柱体急剧放大而 DIF 早已钝化，此时应结合量比（D11）与换手判断。

04什么时候不准

① 横盘缩量阶段：DIF 与 DEA 反复缠绕，金叉死叉平均 5–8 根出现一次，几乎无预测价值；② 连续一字板：价格跳空使 EMA 快速抬升，柱体失真；③ 复权切换：前复权与不复权的历史 DIF 不同，比较跨期信号必须先统一复权方式；④ 停牌复牌首日：缺口被当作单根计入，DIF 出现阶跃。

空态与空结果

三类空态：无数据、无搜索结果、数据不足（正常状态，不画平线）

自选还是空的

从行情列表或搜索结果里点 ★ 加入；也可以先看指数与板块概览建立观察清单。

state.db · watchlist rows = 0 · 分组「全部」为空

没有匹配的指标

关键词「背离」在中文名与缩写中均未命中。试试「RSI」「量比」「MACD」，或到分类中浏览。

query="背离" · 0 / 105 · 耗时 3ms

数据不足以计算

BOLL(20) 需要 20 根，当前只有 8 根。这是正常状态：不补 0、不画平线；回填完成后自动出现。

indicator=BOLL · warmup=20 · available=8 · result=NaN(8)
空态规则来自 v3 §2.2
① 空态必须给出下一步动作，不能只写「暂无数据」；② 数据不足属于正常状态，文案要写清「需 N 根 / 当前 M 根」；③ 搜索空结果保留用户输入，提供可点击的建议词；④ 所有空态不做骨架屏，骨架屏只用于首装与重算超过 120ms 的场景。

错误态

按 v3 的三类错误编排：可纠正 / 可重试 / 不可恢复；每类都有 trace id 与建议动作

参数越界 可纠正

RSI 周期必须落在 2–200 之间，当前输入 260。前端拦截，不发起计算请求；改回范围内自动恢复，不需刷新。

E_PARAM_OUT_OF_RANGE · indicator=M01 RSI · field=period · value=260 · range=[2,200] · trace=4f2a91c0

上游超时 可重试

拉取 2026-11-05 日线时连续 3 次超时。已保留本地已有数据，图表继续可用；重试只补缺失批次。

E_UPSTREAM_TIMEOUT · provider=mock-v3 · batch=sim-2024/part-00013 · attempt=3 · retry_after=65s · trace=8b10ee42

数据集校验失败 不可恢复

manifest 校验和与磁盘文件不一致，疑似写入中断。为避免画出错误 K 线，已拒绝加载该数据集。

E_DATASET_CORRUPT · dataset=sim-2024@d41f · expect=7c1e…8f02 · actual=91ab…44c7 · trace=cd7701b8

指标不可计算 可解释

成交量为 0 的停牌区间，MFI 的分子分母同时为 0；引擎返回 NaN 而非 0，面板标注「停牌无定义」。

E_UNDEFINED_ON_ZERO_VOLUME · indicator=D05 MFI · bars=14 · flags=SUSPENDED · trace=1e55b093
