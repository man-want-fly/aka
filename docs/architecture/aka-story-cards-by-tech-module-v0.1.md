## 1. 划分口径

1. **模块边界以架构文档为准**：Rust 按 workspace crate 划分，前端按 `app/pages`、`features/*`、`components`、`lib`、`styles` 划分；不新造模块名。
2. **一卡一主责**：每张卡只归一个「主责模块」，其余涉及模块列在「协作模块」；跨层卡（E-08、门禁）归入 C 类。
3. **主责 = 改动落点**：主责模块是该卡大部分 AC/代码所在层，不按 Epic 归属机械切分。
4. **状态沿用台账**：`已交付 / 条件交付 / 数值层已具备 / 渲染层已具备 / Blocked / Blocked-AC / 未开始`；不新增状态。
5. **合并卡**：E-08 中并入宿主卡的 4 张仍列出，但标注宿主，避免排期重复。
