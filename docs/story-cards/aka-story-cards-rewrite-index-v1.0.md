### EP-05 改写要点

1. 原 `S-02.06-01`（批量按需计算与冷算性能，5 点）一张卡塞了三件事（批量、区间、序列装配），按规则「一个 Story ≈ 1–5 点、能独立演示」拆成 `01 / 06 / 08` 三张。
2. 原 `S-02.06-02`（缓存命中 / 世代丢弃 / 旧结果不渲染，4 点）混了后端缓存与前端丢弃，拆成 `02 / 03 / 04 / 05` 四张，**「旧结果不渲染」移交 EP-07**（前端 generation 比对，`WorkbenchPage.tsx:583/820/861`）。
3. 原卡「世代丢弃」写作后端职责，代码事实是：后端 `CalcResponse.dataset_generation` 只回显，无任何丢弃逻辑；丢弃在前端 `generation` ref。此口径已在新卡中改正。
4. 删除原卡所有「`CalcCacheKey` 结构体」「六元组缓存键」「`kernels/` 子目录」「`BarFlag`」表述，改为 `calc_key()` 字符串、7 维 + 区间、`kernels.rs`、`Vec<String>`。
5. 新增卡依据代码缺口：`calc_cache` 无上限无淘汰（`core.rs:317` 只有 `Mutex<HashMap>`），见 `S-EP05-05`；`QualityFlag` 8 变体无线上字符串冻结测试，见 `S-EP05-07`；DTO 无 wire 形状测试，见 `S-EP05-09`。
