### EP-05 改写要点

1. 原 `S-02.06-01`（批量按需计算与冷算性能，5 点）一张卡塞了三件事（批量、区间、序列装配），按规则「一个 Story ≈ 1–5 点、能独立演示」拆成 `01 / 06 / 08` 三张。

3. 原卡「世代丢弃」写作后端职责，代码事实是：后端 `CalcResponse.dataset_generation` 只回显，无任何丢弃逻辑；丢弃在前端 `generation` ref。此口径已在新卡中改正。

5. 新增卡依据代码缺口：`calc_cache` 无上限无淘汰（`core.rs:317` 只有 `Mutex<HashMap>`），见 `S-EP05-05`；`QualityFlag` 8 变体无线上字符串冻结测试，见 `S-EP05-07`；DTO 无 wire 形状测试，见 `S-EP05-09`。

### EP-07 改写要点

1. 原 4 张卡（主题/涨跌色/密度与格式/SIM）按「能独立演示 + 可单独致红」重切成 6 张：`S-06.01-01` 拆成 `01`（首帧预置，未实现）与 `02`（三态矩阵 + 系统订阅）；`S-06.02-01` 拆成 `04`（密度）与 `05`（数字格式）。原卡把「密度」和「数字格式」写成同一张，两者落点、门禁、回滚方式都不同，无法共用一条 AC。
2. 新增 `S-EP07-01`：代码里存在真实的**首屏错色**缺陷 —— `index.html:2` 硬编码 `data-theme="dark" data-colormode="redUp"`，而 `applyTheme` 只在 `App.tsx:60` 的 `useEffect` 里执行，即首帧之后。浅色用户必然先闪一片深色，绿涨用户必然先闪红涨。修法是 `index.html` 里一段同步内联脚本，卡面直接给出脚本全文与 6 组 vm 断言。
3. 原卡「主题三态」没有写「持久化的是模式还是解析结果」。代码事实是 `applyTheme` 存 `mode`（含 `system`），这是对的；新卡把它写死成 AC，并新增反例「存成 `resolved` → 用户的 system 选择丢失」。
4. 原卡「涨跌色不硬编码」无法证伪。新卡改为 `verify_tokens.mjs` 的 6 条可执行检查：色值只许出现在 `--up/--down` 定义行、`greenUp` 块内 `--rise: var(--down)`、`.pos/.neg/.flat` 三条声明逐字匹配、`app/src/**/*.{ts,tsx}` 的十六进制/rgb/`color: "red"` 命中数为 0。
5. 密度卡发现真实**兜底缺失**：`--row-h` 只在 `[data-density="compact"|"comfy"]` 下定义，首帧无 `data-density` 时 `var(--row-h)` 无值。新卡要求在 `:root` 补 `--row-h: 28px`，并作为反例 5。同时**不拆 `density.ts`**：`settings.ts` 首行 `import { ipc } from "./ipc"`，Node 无法直接 import（实测 `ERR_MODULE_NOT_FOUND`），门禁改为静态解析 TS 常量与 CSS 变量。
6. 格式卡纠正三处沿用错值：①`toFixed` 全仓是 **54 行 / 76 次**（不是 54 次）；②`verify-number-format.mjs` **只扫 `src/components`**（54 行里只覆盖 4 行）；③`verify:format` 这个 npm script **存在但 `ci.yml` 从未调用**。本卡要求扫到 `components/pages/features/lib` 并把命令接进 CI。
7. 格式卡没有把 `changePct.ts` 删掉：`verify-r03-three-state.mjs` 依赖它（该脚本自述「判据与页面共用，不重写第二套」）。改为**委托** `formatPct`，输出逐字不变，避免连带 EP-08 三态证据。
8. SIM 卡纠正「SIM 角标是产品常驻标识」的误解：`SimBadge` 无 `simulated` 入参、恒显示，而三处页面其实**都已经拿到** `simulated` 字段（`snapshot.simulated` / `bars.provenance.simulated`）。新卡把 `simulated` 改为必填，`false` 返回 `null`，并锁死 `className`/`title`/文案三个字符串不动（DOM 证据依赖）。
9. 全部 6 张卡的门禁都用 **Node 22 直接跑 `.ts` / 静态解析** 取证（`node app/scripts/verify_*.mjs`），不引入任何测试框架 —— 仓库无 `npm test`、无 ESLint，见 `B-05-03`。
