## 状态定义（只用这五种）

| 状态 | 含义 |
|---|---|
| `已交付` | 卡上**全部 AC** 均有对应层级的测试/断言证据 + 代码；渲染层 AC 有 DOM/样式断言，数据层 AC 有单测 |
| `条件交付` | 主流程可用、有部分证据，但存在明确未满足的 AC（已逐条写明缺口） |
| `渲染层已具备` | 页面/组件已存在，渲染 AC 至少部分取证，但仍有差异条款未做 |
| `数值层已具备` | 引擎/数据层实现与单测已过，但渲染 AC 未通过（含**已进 UI 但关键差异条款未取证**）；按规则**不算已交付** |
| `未开始` | 无对应代码或仅有工具函数，未接入任何页面 |
