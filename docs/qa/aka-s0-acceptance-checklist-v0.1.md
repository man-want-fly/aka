## 0. 怎么用这份清单（QA 先读 5 条）

1. **S0 是地基 Sprint，不是功能 Sprint。** 判定对象是「契约是否冻结、证据是否可复现」，**不是**「页面是否可用」。S0 结束时 E-01/E-03/E-04/E-07 的大部分页面仍未实现，属正常。
2. 每条检查项有三个判定等级，**等级决定 QA 是否开缺陷**：
   - **A｜S0 内可完整判定**：不依赖后续 Sprint，可直接跑通并给通过/失败。
   - **B｜仅契约层可判定**：只核 schema/DTO/字段/校验器；界面行为由后续 Sprint 判定，S0 不判失败，只判「契约是否就位」。
   - **C｜S0 内不可判定**：依赖未实现能力（真实数据源、Parquet、口径内容、页面）。**只登记、不判定**，避免把「还没做」误判为缺陷。
3. 所有命令在**仓库根目录**执行；基准机 **M1 / 16GB / SSD**，冷启动后首次交互取样，P95 取 ≥30 次。
4. 数值比对一律给出**容差**：价格/金额 `1e-6` 相对；振荡/比率 `1e-4` 绝对；计数必须整数完全相等；百分比显示 2 位小数（`+`/`−` U+2212）。
5. 证据必须可留存：**截图（含时间戳）＋日志片段＋SQL 结果＋文件校验值**。口头确认、录屏不含逐帧的不算证据。

## 3. 无对应 Story 卡的技术任务验收口径

这些事项在 57 张卡里**没有 AC 承载**（卡是产品行为，卡不含工程流水线）。判定原则：**「有可重复执行的证据 + 有冻结的契约 + 有红灯样例」三条全满足才算完成**，不得用「已配置」「本地能跑」代替。

### T-01 DateRange 改造（3.0 人日）

| 项 | 口径 |
| --- | --- |
| 完成定义 | 所有查询 API 的入参为 `{code, period, adj, from, to}`（ISO 日期）；返回值含 `requested/returned/clipped` 与 `insufficient` 标记；交易日历为唯一日期权威；下标不再出现在 IPC |
| 验证方法 | ① 抓 10 条 IPC 报文，检查无 `start_index/end_index`；② 构造 5 组边界：区间早于数据起点、晚于终点、含停牌整周、`from>to`、单日区间；③ 周/月聚合对拍 3 只标的 |
| 期望证据 | 报文快照 JSON；5 组用例的实际返回；对拍 CSV |
| 不通过条件 | 任一报文仍传下标；`from>to` 未返回明确错误码；停牌整周被算成 1 根 K 线；聚合根数 ≠ 交易日历周数 |

## 4. 影响面：DateRange 从「下标」改为「日期区间」后需同步修订的卡

结论：**7 张卡的 AC 表述、6 张卡的字段/口径表述需要改**。核心冲突是：
- 卡内仍以「根数/下标」描述视口与窗口（`可视 120 根`、`第 10~12 根索引`、`可视区 200 根`）；
- 缓存键 6 元组 `code + period + adj + indicator_id + params_hash + dataset_generation` **不含日期区间**，DateRange 改造后必须裁定「全序列计算后切片」或「键内加区间哈希」——**这条不改会在 S4/S5 直接返工**。

| 卡号 | 现表述（问题点） | 建议改法 | 优先级 |
| --- | --- | --- | --- |
| **S-02.06-02** | 缓存键 6 元组，不含区间 | 二选一并写入卡：①**推荐**「指标按全序列计算，视口只切片」→ 键不变，但须加 AC「切片不触发重算」；②键扩为 7 元组加 `range_hash`，并补 TTl/淘汰说明 | **P0（阻塞 S4/S5）** |
| S-02.06-01 | 补1「可视区 200 根」 | 改为「可视区 = `[from,to]` 对应交易日根数，S0 后由服务端 `returned` 计数给出」 | P0 |
| S-02.07-01 | 「可视 120 根」「三次放大保持 20 根」 | 保留像素级交互断言，但把基准量改为「日期区间 ↔ 根数映射」：先声明 `from/to`，再断言映射后的根数 | P1 |
| S-02.07-02 | 补1「第 10~12 根索引为 NaN」 | 改为「某 3 个连续交易日为 NaN」，保留「断线/空心点」判据 | P1 |
| S-02.02-01 | AC-02.02-01「周线根数等于交易日历自然周数」 | 表述已兼容，但需补一句「`from/to` 先裁剪到交易日历再聚合；停牌整周不生成」 | P1（仅补口径，不改 AC 编号） |
| S-04.01-02 | 「5 日/20 日」未声明是交易日还是日历日 | 明确「按**交易日数**（20 日 = 需 21 个收盘价）」；补1 的 `需要 21 个交易日` 与此对齐 | P1 |
| S-04.02-02 | 「区间涨跌幅」未声明区间边界含否端点 | 明确「闭区间 `[from, to]`，首日以区间前一日收盘为基准」 | P1 |

| S-07.03-02 | 9 字段未含 `coverage_start/end` 的展示口径 | 补「区间以 ISO 日期展示，含端点」；与页脚 S-02.08-01 同源 | P1 |

> 上述改动**本次不落卡**（按约束只登记）。建议由产品在 S1 开工前一次性回写，避免 S1/S3/S5 三次返工。
