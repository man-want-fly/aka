## 1. AC-03.04-05（补1）：59 vs 60

**卡片原文**：当前标的 59 根日线，添加 EMA(20)，提示「EMA 需要 60 根，当前 59 根」。

**BA 已修正（2026-11-06）**：`AC-03.04-05（补1）` 现为「19 根日线，添加 EMA(20)，不画线并提示
『EMA 需要 20 根，当前 19 根』；补到第 20 根后重算并画出首根有效值」。59 是 DEMA/TEMA 的 `3N−1`
门槛，已从本条剥离。

**代码侧复核**：`app-core/src/core.rs` 的不足提示按 `required = warmup + 1` 生成，
EMA(20) 输出「需要至少 20 根（预热 19）」，行为正确。渲染侧只连接有限值，19 根时 EMA 全 NaN，
实际不会画线。

**两项剩余缺口的明确处置（不做）**：

- ①「未按 AC 停止画线」：**不做额外代码改动**。当前渲染器按有限值断线，19 根时无有限点即无线；
  不新增独立的「停止画线」开关，避免为一条 AC 增加冗余状态。
- ②「补到 20 根后出首值的实机取证」：**不做**。本地数据集固定 520 根，无法在不改数据管线的前提下
  构造 19→20 根的实机场景；数据层已由 `edge_b1_below_min_window` 夹具覆盖首值下标 19。
  该项只能由 BA/QA 决定是否值得为取证单独造样本，本轮不挂「已验收」。

## 2. AC-03.04-11：T19 / T20 / T21 / T22 入主图

**原缺口**：主图叠加下拉只有 B2 的 11 项，T19–T22 虽在 manifest 中但 UI 不可选。

**处理（已补齐）**：

- `model.ts` 新增 `B1_OVERLAY_CHOICES`（T19 回归预测、T20 回归截距、T21 R²、T22 回归斜率），
  并入主图叠加下拉；T19/T21 标签带「beta」，不进入默认叠加组合（默认仍 `T09 + T24`）。
- `buildInstances` 追加 `T19/T20/T21/T22` 实例，参数走 manifest 默认值。
- 单位随 manifest：元 / 元 / 无量纲 / 元每根；tooltip 同帧一致性由既有逐根等值校验覆盖。

## 3. AC-03.04-15：E13 BIAS 入副图折线

**原缺口**：副图下拉无 E13，三条 BIAS 线不可见。

**处理（已补齐）**：

- `SUB_CHOICES` 追加 `E13 BIAS`；副图渲染沿用通用 `line` 分支，三条线的图例取 manifest
  `labelZh` → `BIAS(6) / BIAS(12) / BIAS(24)`。

  （与 AC-02.07-03 的空洞渲染共用同一实现）。
