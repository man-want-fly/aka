## 2. Q-01 M02 KDJ

### 2.1 推荐值

| 歧义点 | 裁定 | 理由 |
|---|---|---|
| 零区间（`HHV=LLV`）的 RSV | **取 50** | 通达信在高低同价时按中位处理，A 股看盘上表现为 K/D 走平于 50 附近；取 50 还能避免除零 NaN 造成副图断线，且平盘不产生假信号 |
| K / D 种子 | **50 / 50** | 通达信 KDJ 的递归初值即 50；固定种子使「首根」可复现，不因数据起点漂移 |
| 额外预热 | **不需要**，首值下标 `period-1 = 8` | 种子固定后第 9 根（下标 8）即由 `RSV` 递推出有限值；再加预热只会推迟首值，与 A 股软件「第 9 根出 KDJ」不符 |
| 输出线 | **K / D / J 三线** | PRD 与规划 CSV 均标「K/D/J 三线」；J 是国内 KDJ 的必备读线，不能只出 Stoch 的 K/D |
| 平滑写法 | `K=((k-1)·K[-1]+RSV)/k`、`D=((d-1)·D[-1]+K)/d`，`k=d=3` | 等价于通达信 `SMA(X,3,1)`，即 2/3 前值 + 1/3 新值 |

**基准来源**：通达信。同花顺与 TA-Lib 的差异仅作备注——TA-Lib 的 `STOCH` 不含 J，且 K/D 用简单移动平均；同花顺 KDJ 与本口径一致但默认参数常为 9/3/3。三者不一致时，**以通达信 + A 股三线读法为准**。

### 2.2 可测断言（开发直接写夹具）

| 编号 | 输入 | 期望输出 |
|---|---|---|
| Q-01-A | 9 根 `H=L=C=10`（零区间） | 下标 0–7 全 `NaN`；下标 8 `K=D=J=50.0`（误差 ≤1e-9） |
| Q-01-B | 30 根单边上涨：`C[i]=10+i`、`H=C+1`、`L=C−1` | 下标 8：`RSV=100` → `K=(2×50+100)/3=83.3333`、`D=(2×50+83.3333)/3=77.7778`、`J=3K−2D=88.8889`（误差 ≤1e-4） |
| Q-01-C | 同 Q-01-B，检查首值位置 | 下标 7 全 `NaN`；下标 8 三线同时有限 → 证「无额外预热」 |
| Q-01-D | 任取连续 5 根 | `J[i]=3·K[i]−2·D[i]` 逐根恒等（误差 ≤1e-9） |
| Q-01-E | 参数 `k=2,d=2` | 首值仍为下标 8；`K[i]=(K[i−1]+RSV[i])/2`，可手算对照（证明 `k/d` 参与递推，而非写死 3） |

## 3. Q-02 M24 Mass Index

### 3.1 结论：改 CSV，不改实现

- 采用实现口径：`range=H−L`；`first=EMA9(range)`；`second=EMA9(first)`；`Mass=Σ(first/second, 25)`。
- 首个有效值下标 = `2×(9−1)+25−1 = 40`，因此**规划 CSV 与 PRD 的 `warmup=30` 是错的，应改为 40**。
- 理由：`30` 只有在「第一次 EMA 从下标 0 起逐根递推（无 SMA 种子）」时才可能成立；本产品 T02 EMA 已冻结为「种子 = 前 N 根 SMA，下标 N−1 起有效」，B1 的 M06、B3 的 M25 都依赖该基线。为一条指标改 EMA 种子，会连带改掉 T02 / M06 / M08 / M25 的首值与全部黄金夹具，属**破坏性口径变更**，收益为零。
- 结论：这是**规格层笔误**，不是实现错误。口径页、PRD 附录 A、规划 CSV 三处统一为 **40**。

### 3.2 可测断言

| 编号 | 输入 | 期望输出 |
|---|---|---|
| Q-02-A | 520 根合成 OHLC，`ema=9,sum=25` | 下标 0–39 全 `NaN`；下标 40 起有限 |
| Q-02-B | 同 Q-02-A | 下标 40 的值 = `Σ_{i=16}^{40} (first[i]/second[i])`，手算 25 项求和，相对误差 ≤1e-6 |
| Q-02-C | 60 根 `H=11,L=9`（`range` 恒 2） | 下标 40 起 `first=second=2` → `Mass` 恒 `25.0`（误差 ≤1e-9） |
| Q-02-D | 60 根 `H=L=C=10`（`range=0`） | 比值 `0/0` → 全 `NaN`，不得输出 0 或 25 |

## 4. Q-03 M25 Elder Impulse

### 4.1 推荐值

| 歧义点 | 裁定 | 理由 |
|---|---|---|
| 柱系数 | **2×**（与 M06 同源） | Elder 原版直接复用 MACD 柱；A 股 MACD 柱一律 2×，M25 若用 1× 会与副图 MACD 柱高低不一致，用户会当成 bug |
| 脉冲对象 | **`EMA13(hist)`**，`hist` 为上游 2× 柱 | Elder 原文即「MACD 柱的 13 期 EMA」；换成 EMA 斜率会改变指标定义，且无 A 股软件可对照 |
| 判定顺序 | **先判 `hist` 符号，再判脉冲差分**；不要求柱穿越零轴 | Elder 三色本质是「方向 × 动能」两维；要求「穿越」会把持续同向行情长期压成中性，与「脉冲」语义不符 |
| 状态值 | `{+1, 0, −1}`：`hist>0 且 impulse[i]>impulse[i−1] → +1`；`hist<0 且 impulse[i]<impulse[i−1] → −1`；其余 `0` | 两维同向才给方向，任一反向或 `hist=0` 一律中性 |
| 渲染色 | **+1 红 / −1 绿 / 0 蓝** | 本产品全站「红涨绿跌」是硬约束（卡集 §0.1）；Elder 原版「绿多红空」在 A 股会直接读反，必须反转并在口径页显式说明「与 Elder 原版配色相反」 |
| 首值 | `state` 下标 **46**；`impulse` 自 45 起 | `hist` 自 33、`impulse` 需 13 个 hist → 45；`state` 还要前一根 impulse → 46 |

### 4.2 可测断言

| 编号 | 输入 | 期望输出 |
|---|---|---|
| Q-03-A | 40 根单边上涨（`C[i]=10+0.5i`） | 下标 0–32 全 `NaN`；下标 33 起 `hist>0`；下标 45 起 `impulse` 有限；下标 45 `state` 仍 `NaN` |
| Q-03-B | 同 Q-03-A，延到 60 根 | 下标 46 起 `state=+1`（`hist>0` 且 impulse 逐根上行）；不得出现 `−1` |
| Q-03-C | 先涨 40 根再急跌 20 根 | 下跌段出现 `hist<0` 且 impulse 下行 → 下标首次满足处 `state=−1`；`hist<0` 但脉冲仍上行时 `state=0` |
| Q-03-D | 构造 `hist>0` 但 `impulse[i]≤impulse[i−1]` | `state=0`（证明「符号对、动能反」不给方向） |
| Q-03-E | 60 根 `C=10` 常数 | `hist=0` → 下标 33 起 `hist=0`；`state` 下标 46 起全 `0`，不得为 `NaN` 以外的 ±1 |
| Q-03-F | 检查柱口径 | 任一根 `hist[i]=2×(DIF[i]−DEA[i])`，与 M06 同参数输出逐根相等（误差 ≤1e-9） |

## 7. 两处 CSV 疑笔误（非 beta）

| 指标 | CSV / PRD 值 | 正确值 | 判定 | 依据 |
|---|---|---|---|---|
| M10 Momentum | `warmup=12`（默认周期 10） | **10**（首个有效值下标 10） | **笔误**，非双参数 | 公式只有 `period` 一个参数，`MOM=C−C[-N]`；12 与 N=10 无法同时成立，属把 M09 ROC 的 12 抄到了下一行 |
| M20 Vortex | `warmup=20`（默认周期 14） | **14**（首个有效值下标 14） | **笔误**，非双参数 | `VI+/VI−` 只有 `period` 一个参数，窗口 `N=14`；20 是通用默认值的残留，与实现窗口无关 |

**修正范围**：`docs/planning/aka-indicator-batches-v0.1.csv`、PRD 附录 A.3 的「预热」列、B3 卡内首值位、口径页 M10 / M20 段；manifest 的 `period.default` 保持 10 / 14 不变。

> 说明：规划 CSV 的 `warmup` 列混用「0 基下标」与「1 基根数」，本文件只在**两种计法都解释不通**的三处动刀
> （M10 12→10、M20 20→14、M24 30→40、M25 34→46）；其余 1 基写法（M02 9、M04 14、M05 20、M06 34、M08 34、
> M19 25、M26 7）保留不动，不借机重排。
