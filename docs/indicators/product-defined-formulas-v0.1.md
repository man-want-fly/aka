## 1. 四条共用规则

### 1.1 横截面样本池

`E02`、`F15`、`F16` 都是横截面（广度 / 排序）指标，共用同一套池规则：

| 规则 | 口径 |
|---|---|
| 池来源 | 当前数据集全部标的（MVP 为样本包 120 只） |
| 排除 | 指数行（`000001.SH`、`399001.SZ`、`399006.SH` 及 manifest 标记为 index 的行）；北交所标的**计入**（属个股） |
| 当日有效标的 M | 该交易日 `C(t)` 与公式所需的前值/均线均存在，且非 `SUSPENDED`、非 `EX_RIGHTS` 当日、非上市首日（无前收） |
| 缺 bar 处理 | **该标的当日剔除**，不前向填充、不补零；不改变其他标的权重 |
| 最小样本 M | **M < 20 → 当日输出 `NaN`**（整条线断点，不输出 0、不输出 50） |
| 样本口径标注 | 副图标题右侧固定「样本口径 · {M} 只」，M 为当日有效数（见 F-03.04 / D-22） |
| 复权 | 价格类计算用**前复权**（D-16）；`F15` 的涨跌停价判定例外，必须用**不复权收盘价**（见 §3.2） |

### 1.2 预热与 `warmupBars` 的统一语义

目录页与抽屉的「预热」列直接读 manifest `warmupBars`，其语义已冻结为：

> `warmupBars` = **首个有效值下标 + 1**，即「至少需要多少根 K 线才出第一个点」（0 基下标，见 `CatalogPage.tsx:45`）。

因此本节每条都同时给「首值下标」和「应写入 manifest 的 `warmupBars`」，两者不得混用。

### 1.3 数值与展示约定

| 项 | 口径 |
|---|---|
| 数值类型 | `f64`；内部不截断，展示层按条目标注精度 |
| `NaN` | 序列断点（副图不连线、悬停显示「—」），**不写 0、不写 `null` 以外的哨兵值** |
| 无穷 | 禁止出现 `∞`；会产生无穷的除零一律按 §1.4 退化为 `NaN` |
| 缓存键 | `dataDate + adj_mode + timeframe + indicator_id + params`；任一变动视为不同序列 |
| 跨日一致性 | 同一 `dataDate` 重复计算结果必须逐点一致（禁止用运行时 `now` 做窗口） |

### 1.4 退化处理总则（四条通用）

| 场景 | 处理 |
|---|---|
| 分母为 0 | 输出 `NaN`；不做「上限封顶」「取 0」「取 100」等任何替代值 |
| 数据不足（M < 20 或前值缺失） | 输出 `NaN`，且不把该点计入任何统计 |
| 常数序列导致零带宽 / 零区间 | 该条另有专条（`E02` 见 §2.4，`F15` 见 §3.4，`F16` 见 §4.4） |
| 参数的非法输入 | 越界参数在入口处拒绝（返回配置错误，不静默夹到边界） |

## 2. `E02` RS 分位（RS Percentile）

### 2.1 定义

对标的 `i`、交易日 `t`、参数 `P`（默认 60）：

```
RS_i(t)   = C_i(t) / C_i(t − P) − 1          # 相对强弱（区间涨幅），小数
RS_i(t)   = NaN  if C_i(t−P) 不存在 or C_i(t−P) ≤ 0
```

其中 `C` 为前复权收盘价。`C_i(t−P) ≤ 0` 直接剔除该标的（前复权在极端除权下可能出现非正价，不允许产生 `±∞`）。

分位（**横截面**，不是时序）：

```
M(t)      = t 日有效标的数（满足上式、且非 SUSPENDED）
rank_i    = t 日 RS 升序名次，从 1 开始；并列取平均名次
            例：两个并列第 3 → 两者均取 3.5
Pct_i(t)  = (rank_i − 1) / (M − 1) × 100      # 0 ~ 100
Pct_i(t)  = NaN  if M < 20 or M = 1
```

**输出的是「所选标的自己的分位」**：副图每个交易日一个点，值为该标的当日横截面分位。不是「分位对应的标的」。

### 2.2 参数

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `period` | **60** | [20, 250] | 回看根数（交易日），即 `C(t)/C(t−period)` |
| 池 | 固定 | — | §1.1，不开放给用户改 |

参数面板只暴露 `period`；修改后重新计算，缓存键含 `period`。

### 2.3 预热

| 项 | 值 |
|---|---|
| 首值下标 | **`period`**（默认 60，0 基） |
| `warmupBars` | **`period + 1`**（默认 **61**） |
| 依据 | 下标 `period−1` 时 `C(t−period)` 尚不存在；下标 `period` 才有第一个可算的 `RS`。注意还需 `M ≥ 20`，若当日达标标的不足 20，首点会继续后移 |

> **manifest 待改**：当前 `warmupBars=60`，应为 **61**（见 §6）。

### 2.4 退化处理

| 场景 | 结果 |
|---|---|
| `C_i(t−P)` 缺失（新上市 / 停牌前无 bar / 缺行） | 该标的当日剔除，不参与 M |
| `C_i(t−P) ≤ 0` | 该标的当日剔除 |
| `M < 20` | 当日全部输出 `NaN`（横截面过窄时分位无意义） |
| `M = 1` | `NaN`（分母 `M−1=0`） |
| 全部标的 `RS` 相同（并列） | 平均名次 = `(M+1)/2`，所有人同为 `50.0`，**合法输出**（不是 NaN） |
| 停牌（`SUSPENDED`，量为 0） | 剔除该标的当日 |
| 除权日（`EX_RIGHTS`） | 用前复权价计算，不剔除（前复权已消除跳空） |

### 2.5 可测断言

| 编号 | 输入 | 期望 |
|---|---|---|
| E02-A | 20 只标的，`C(t−60)=100`；`C(t)=100+i`（i=0…19），无停牌 | 下标 59：全 `NaN`；下标 60：`Pct_0=0.00`、`Pct_9=47.37`（=(10−1)/19×100）、`Pct_19=100.00`（误差 ≤1e-4） |
| E02-B | 同上，但第 1、2 只 `RS` 相同且为最小 | 两者名次均 1.5 → `Pct=2.63`（=(1.5−1)/19×100），其余名次顺延 |
| E02-C | 19 只标的（M=19） | 下标 60 仍 `NaN`；第 20 只补入后才出首点 |
| E02-D | 20 只全为 `RS=0`（`C(t)=C(t−60)`） | 全部 `50.00`，不 NaN |
| E02-E | 某只 `C(t−60)=0` 或负数 | 该只剔除 → M=19 → 当日 `NaN`（若池恰好 20） |

### 2.6 口径页文案

> 计算口径：`RS = 收盘价 / P 个交易日前收盘价 − 1`（前复权）；分位为**当日横截面**升序排位 `(rank−1)/(M−1)×100`，并列取平均名次。样本池为数据集全部个股（排除指数），停牌与新上市剔除，当日有效样本少于 20 只时不计算。本指标为**产品自研口径**，手册未给出公式。

## 3. `F15` 涨跌停家数比（Limit Ratio）

### 3.1 定义

```
R(t) = U(t) / D(t)
```

- `U(t)`：`t` 日样本池内**涨停**家数；
- `D(t)`：`t` 日样本池内**跌停**家数。

### 3.2 涨停 / 跌停判定（按 D-18 的板块比例推导）

**必须用不复权收盘价**：涨跌停价由交易所按「前一日不复权收盘价」计算，复权价会引入失真。

```
P_prev,i  = 不复权收盘价(t−1)
L_i       = 该标的当日涨跌幅限制（见下表）
P_up,i    = round_to_cent(P_prev,i × (1 + L_i))     # 四舍五入到 0.01 元
P_dn,i    = round_to_cent(P_prev,i × (1 − L_i))
tol       = 0.005 元                                 # 半个最小价位，吸收 tick 差异

涨停 ⟺ C_raw,i(t) ≥ P_up,i − tol
跌停 ⟺ C_raw,i(t) ≤ P_dn,i + tol
```

| 板块 / 状态 | 判定 | `L` |
|---|---|---|
| 主板沪市 | `60` 开头 | 10% |
| 主板深市 | `00` 开头 | 10% |
| 创业板 | `30` 开头 | 20% |
| 科创板 | `688` 开头 | 20% |
| 北交所 | `8` / `4` 开头 | 30% |
| ST / *ST（主板 `60`/`00`） | 名称前缀含 `ST`（当日名称，见 `namechange`） | **5%** |
| ST / *ST（创业板 `30` / 科创板 `688`） | 同上 | **20%**（与板块一致，按 D-18） |
| 上市首日 / 复牌首日无涨跌幅 | 无前收或标记 `NO_LIMIT` | **剔除**，不计入 U/D/M |

**一字板**：开盘即封板（`O == H == L == C` 且为涨停价）——**计入 U**，本期**不做**「是否含一字板」的口径切换（manifest `notes` 中的「变体：是否含一字板待定」到此结案：默认含）。

### 3.3 参数

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| 无 | — | — | `params = []`（样本池固定，`L` 由板块与 ST 推导） |
| 池 | 固定 | — | §1.1 |

### 3.4 预热

| 项 | 值 |
|---|---|
| 首值下标 | **1**（0 基；需要前收） |
| `warmupBars` | **2** |
| 依据 | 下标 0 无 `P_prev`，无法判定；下标 1 起可算 |

**manifest 当前 `warmupBars=2` 正确，无需改。**

### 3.5 退化处理

| 场景 | 结果 |
|---|---|
| `D = 0`（含 `U = 0` 且 `D = 0`） | `NaN`。**禁止输出 `∞`、禁止封顶 50、禁止把 `D=0` 当 `D=1`** |
| `U = 0`、`D > 0` | `0.00`（合法） |
| `M < 20` | `NaN` |
| `P_prev` 缺失（新股 / 无前收） | 该标的剔除 |
| 停牌 | 剔除（不算涨停也不算跌停） |
| 一字跌停 | 计入 `D`（对称规则） |
| 跌停价计算为 0 或负 | 该标的剔除（`P_prev` 过小，比例法失效） |

### 3.6 可测断言

| 编号 | 输入 | 期望 |
|---|---|---|
| F15-A | 30 只主板股，`P_prev=10.00`；5 只收 11.00、3 只收 9.00 | 下标 0 `NaN`；下标 1 `U=5, D=3, R=1.6667`（误差 ≤1e-4） |
| F15-B | 同上，但收 9.00 的 0 只 | `D=0` → 下标 1 `NaN` |
| F15-C | 30 只中 2 只**主板**名称 `ST xxx`，`P_prev=10.00` | 该两只涨停价按 5% → `10.50`：收 `10.50` 计 U；收 `10.40` **不计** U；若行情出现 `11.00`（超出 ST 涨停价，属数据异常），仍按 `≥ P_up − tol` 计 U，并在质量标记中记 `APPROXIMATED` |
| F15-D | 1 只 `688xxx`，`P_prev=10.00`，收 12.00 | 20% → `P_up=12.00` → 计 U |
| F15-E | 1 只 `P_prev=1.00`，收 0.90 | 跌停价 `0.90` → 计 D；若 `P_prev=0.40`，`P_dn=0.36`，收 0.36 → 计 D |
| F15-F | 某只开盘 `O=H=L=C=11.00` 且主板 | 一字板，计 U（与 F15-A 中收 11.00 等价） |

### 3.7 口径页文案

> 计算口径：涨停/跌停价由前一日**不复权收盘价**按板块比例推导（主板 10%、创业板/科创板 20%、北交所 30%、主板 ST 5%、创业板/科创板 ST 20%），四舍五入到分，容差 ±0.005 元；`R = 涨停家数 / 跌停家数`。样本池为数据集全部个股，停牌、无前收、上市首日剔除；当日有效样本少于 20 只或跌停家数为 0 时不计算。含一字板。涨跌停为**近似推导**（`APPROXIMATED`），不可用于交易决策。

## 4. `F16` Breadth Thrust（广度突破）

### 4.1 定义

```
B_t      = 100 × (1/M_t) × Σ_i 1{ C_i(t) > SMA(C_i, 20)(t) }     # 站上 20 日均线占比，0~100
BT_t     = EMA(B, N)(t)                                          # N 默认 10
```

- `SMA(C_i, 20)(t)`：该标的 20 根**前复权**收盘简单均线（含当日）；
- 判定用**严格大于** `>`：`C_i(t) == SMA` 不计入分子；
- `M_t` 见 §1.1；某标的当日无 SMA20 或缺 bar → 从该日分子分母同时剔除。

EMA 递推：

```
α        = 2 / (N + 1)          # N=10 → α = 0.181818
BT_t     = α × B_t + (1 − α) × BT_{t−1}
BT_seed  = SMA(B, N)            # 第一个 BT 值 = 前 N 个 B 的简单平均
```

> **与经典 Zweig Breadth Thrust 的差异（必须在口径页写明）**：Zweig 原版用「上涨家数 / (上涨 + 下跌)」作宽度比；本产品用「站上 20 日均线占比」作宽度，属**产品自研口径**，阈值与窗口由 BA 定（本节即定稿）。

### 4.2 参数

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `period` | **10** | [5, 30] | EMA 平滑窗口 `N` |
| `maPeriod` | **20** | 固定 | 站上均线的均线周期，本期不开放 |
| 池 | 固定 | — | §1.1 |

### 4.3 预热

| 项 | 值 |
|---|---|
| `B` 首值下标 | **19**（`maPeriod−1`） |
| `BT` 首值下标 | **28**（`19 + (N−1)`，种子取 `B[19..28]` 的 SMA） |
| `warmupBars` | **29**（= 首值下标 + 1） |
| 依据 | 先要 20 根出 `B`；`B` 满 10 个才出 EMA 种子 |

> **manifest 待改**：当前 `warmupBars=10`，应为 **29**（见 §6）。参数变化时：`warmupBars = maPeriod − 1 + (period − 1) + 1`。

### 4.4 退化处理

| 场景 | 结果 |
|---|---|
| `M < 20` | `NaN`（含 `B` 与 `BT` 同时断点） |
| `B` 尚无 10 个有效值 | `BT = NaN` |
| 全部标的当日均无 SMA20 | 当日剔除（`B` 不计算，非 0） |
| 常数序列（全池收盘恒定） | `B = 0.00`（严格 `>` 使 `C == SMA` 不计），`BT` 正常收敛到 0.00，**不 NaN** |
| 全部标的都站上均线 | `B = 100.00`，合法 |
| 停牌 / 缺 bar | 该标的当日剔除出 M |

### 4.5 「急升」展示语义（标记，不改变数值）

副图在上述 `BT` 线上叠加**信号标记**（不新增线、不改 `BT` 值）：

```
信号(t) ⟺ BT_t ≥ 61.5  且  min(BT[t−9 .. t]) ≤ 40
```

- 阈值 61.5 / 40 / 回看 10 根为本产品定义，**只在口径页与 tooltip 出现，不进入公式结果**；
- 标记样式与 `S-03` 通用事件标记一致；同一段连续信号合并为一个标记区间（端点取首次触发日）。

### 4.6 可测断言

| 编号 | 输入 | 期望 |
|---|---|---|
| F16-A | 30 只，`t=0…21` 收盘全 10；`t=22` 起全 11 | 下标 19–21：`B=0.00`；下标 22–28：`B=100.00`；下标 28：`BT=70.00`（种子 =(0+0+0+100×7)/10）；下标 29：`BT=75.4545`（误差 ≤1e-4） |
| F16-B | 同上但 `t=22` 仅 15 只跳涨（15/30） | 下标 22–28：`B=50.00`；下标 28：`BT=35.00`（=(0+0+0+50×7)/10）；下标 29：`BT=37.7273` |
| F16-C | 30 只全恒为 10 | `B=0.00`、`BT=0.00`（下标 28 起），**不 NaN** |
| F16-D | 19 只标的 | 下标 28 仍 `NaN`（M<20） |
| F16-E | `t=22` 起全 11，且 `period=5` | 首值下标 = 19+4 = 23；下标 23 `BT = 平均值(B[19..23]) = 40.00`（=100×2/5） |

### 4.7 口径页文案

> 计算口径：宽度 `B` = 当日收盘价站上 20 日均线的个股占比（0–100，严格大于计入）；`BT` = `B` 的 10 日 EMA（种子为前 10 个 `B` 的简单平均）。样本池为数据集全部个股（排除指数），停牌与不足 20 根的不计入；当日有效样本少于 20 只不计算。信号「急升」= `BT ≥ 61.5` 且近 10 日内曾 `≤ 40`。本指标为**产品自研口径**，与 Zweig 原版（涨跌家数比）不同。

## 5. `M22` CMB（综合动量）— **待定，本期不实现**

### 5.1 现状与裁定

| 项 | 内容 |
|---|---|
| 手册覆盖 | 只有名称「综合动量 / CMB」与一句定性描述，**无公式、无参数、无阈值** |
| 注册表 | `status=planned`（P1）、`completeness=beta`、`specStatus=productDefined`、`warmupBars=20`、`params=[]` |
| 裁定 | **口径待定，本期不实现**；不给出临时公式、不用近似式冒充定稿、不改 `planned` |
| 理由 | CMB 的构成项（趋势 + 动量 + 量能？各自权重？）属产品定义，任何猜测都会把「beta」变成「看似定稿」的错误口径；且 P1 本期条件交付，不阻塞发布 |
