## 2. 逐条裁定与可测断言

### 2.1 R-01 · T13 ATR 移动止损

**裁定**

- 参数 `period=14`、`mult=3.5`（不改）。
- 多头 `long[i] = max(long[i−1], C[i] − k×ATR[i])`，止损单调不减。
- 翻空条件 `C[i] < long[i−1]`（**收盘穿越**）。
- 翻空当根：多头列冻结 `long[i−1]`；空头列重置为 `C[i] + k×ATR[i]`。
- 空头对称 `short[i] = min(short[i−1], C[i] + k×ATR[i])`；`C[i] > short[i−1]` 翻多并重置 `long[i] = C[i] − k×ATR[i]`。
- 未激活一侧 NaN；ATR 未就绪段两侧 NaN。

**可测断言**

| 编号 | 断言 | 取证方式 |
|---|---|---|
| R-01-A | 「盘中最低价跌破前值、收盘收回」的 3 根 K 线：不翻空，空头列仍 NaN | 数值单测 / 夹具 |
| R-01-B | 「收盘跌破前值」：当根多头冻结旧值，下一根起空头值 = `C + 3.5×ATR`，且不等于旧多头值 | 数值单测 |
| R-01-C | 多→空→多往返，每轮空头/多头重置值分别等于 `C ± 3.5×ATR` | 数值单测 |

**开发动作**：manifest `T13.status` 应为 `normal`、`specStatus=manualComplete`，`notes` 含「收盘穿越；翻空重置；裁定 R-01」（现状已满足，核对即可）。

### 2.2 R-02 · T15 一目均衡表

**裁定**

- 参数 `tenkan=9`、`kijun=26`、`senkou=52`、`displacement=26`。
- `tenkan/kijun/senkouB_base = (HHV+LLV)/2`，窗口含当前根。
- `senkouA[i] = (tenkan+kijun)/2[i−D]`、`senkouB[i] = senkouB_base[i−D]`；末尾 D 根 NaN。
- 迟行线 `chikou[i] = close[i−D]`；前 D 根 NaN，不得出现负下标。
- 五线同值首根下标 `senkou−1+displacement = 77`（0 基）。

**可测断言**

| 编号 | 断言 | 取证方式 |
|---|---|---|
| R-02-A | 520 根输入下，先行带 A/B 最后一个有效值下标 = `519−D`，末尾 D 个为 NaN | 数值单测 / 夹具 |
| R-02-B | 迟行线第 `i` 值 = `close[i−26]`（`i≥26`）；`i<26` 为 NaN | 数值单测 |
| R-02-C | 把最后一根收盘改为极大值，已发布段不出现未来值（只影响末端留白区） | 数值单测 |

**开发动作**：manifest `T15.status=normal`、`specStatus=manualComplete`，`notes` 含「末尾 D 根留白；裁定 R-02」（现状已满足，核对即可）。

### 2.3 R-03 · T16 抛物线转向（保留 beta）

**裁定（推荐值）**

- 参数 `step=0.02`、`increment=0.02`、`max=0.2`（以 manifest `step/increment/max` 为准）。
- 初始方向不固定多头：`close[1] ≥ close[0]` 为多，否则为空；首根有效值下标 1。
- 首根 SAR：多头 `low[0]`、空头 `high[0]`。
- 反转当根 SAR 取旧 EP，AF 重置为 `0.02`，EP 更新为当根极值；AF 封顶 `0.2`。

**可测断言**

| 编号 | 断言 | 取证方式 |
|---|---|---|
| R-03-A | 单调上涨 40 根：SAR 全在价格下方，首值 `low[0]`；单调下跌 40 根对称 | 数值单测 |
| R-03-B | 第 `i` 根反转：`SAR[i]=EP_prev`、`AF[i]=0.02`、EP 更新为当根极值 | 数值单测 |
| R-03-C | 长趋势 100 根：AF 到 `0.2` 后不再增长 | 数值单测 |
| R-03-D | `close[1] == close[0]` 的退化序列：按多头处理且无异常分支 | 数值单测 / 常数夹具 |

**保留 beta 的理由（为什么无法定论）**

1. 初始方向与首根 SAR 在通达信 / 同花顺 / TA-Lib 间不一致，A 股软件无公开公式可逐点核对。
2. 现有黄金夹具只证明与本实现自洽，不能证明与任一商业软件一致。
3. 解除条件：取得**至少一家**商业软件的逐点对照样本后重裁；在此之前 `status=beta`、`specStatus=partial`，UI 若接入需带 beta 徽标、不进默认组合。

**开发动作**：manifest `T16` 当前已被置为 `normal`，**需回退为 `beta` / `partial`**，`notes` 保留「裁定 R-03；对照待补；保留 beta」。

### 2.4 R-04 · T23 轴心点

**裁定**

- 无参数；只用 `i−1` 根的 `H/L/C`：`P=(H+L+C)/3`、`R1=2P−L`、`S1=2P−H`。
- 周期归属：D→上一交易日、W→上一周、M→上一月；切周期后随聚合数据重算，不跨周期复用。
- 只输出 P/R1/S1；首根 NaN；当根改成极端值不得影响输出。

**可测断言**

| 编号 | 断言 | 取证方式 |
|---|---|---|
| R-04-A | 第 `i` 根 P = 第 `i−1` 根 `(H+L+C)/3`；用当根算出的值必须不同 | 数值单测 |
| R-04-B | D→W 切换后 P 使用上一周聚合 K 线，且与 D 周期值不相等 | 集成 / 夹具 |
| R-04-C | registry outputs 只有 `p/r1/s1`，无 `r2/r3/s2/s3` | 读 registry |

**开发动作**：manifest `T23.status=normal`、`specStatus=manualComplete`，`notes` 含「上一周期；仅 P/R1/S1；裁定 R-04」（现状已满足，核对即可）。

### 2.5 R-05 · T24 最高最低

**裁定**

- 参数 `period=20`（2~200）。
- `UP=max(H[i−N+1..=i])`、`DN=min(L[i−N+1..=i])`，**含当前根**，原始值直取。
- **不增加中轨/带宽输出**；首值下标 `N−1`；窗口不足或含 NaN 输出 NaN。

**可测断言**

| 编号 | 断言 | 取证方式 |
|---|---|---|
| R-05-A | 第 20 根 `UP=max(H[0..19])`；改成 `H[0..18]` 结果必须不同 | 数值单测（AC-03.05-03） |
| R-05-B | outputs 仅 `hhv` / `llv`，无 `mid` / `width` | 读 registry |
| R-05-C | 同价 30 根：`UP=DN=该价`，无 `0.00` 伪值 | 常数夹具 |

**开发动作**：manifest `T24.status=normal`、`specStatus=manualComplete`，`notes` 含「含当前根；无中轨/带宽；裁定 R-05」（现状已满足，核对即可）。卡 `S-03.05-01` 已写明。

### 2.6 R-06 · V08 GAPO 跳空

**裁定**

- `GAPO = (Open − 前收) / ATR(period) × 100`，**`period` 默认 14**，Wilder 平滑。
- 正为向上跳空、负为向下跳空，**不取绝对值、不筛同向**；`Open = 前收` 输出 0（合法）。
- ATR 未就绪（前 14 根）或 `ATR=0` → NaN；首值第 15 根（0 基 14）；容差 `relative:1e-6`。

**口径冲突（需一并修）**

| 位置 | 现值 | 应改为 |
|---|---|---|
| manifest V08 `params.period.default` | `20` | `14` |
| `b2-channel-volatility.md` V08 第 1 行 | 「ATR 周期默认 20」 | 「ATR 周期默认 14」 |
| manifest V08 `notes` | 已写「ATR14 / 首值第 15 根」 | 保留，与改后默认值一致 |

**可测断言**

| 编号 | 断言 | 取证方式 |
|---|---|---|
| R-06-A | 高开 2%、ATR=前收 1% → `GAPO ≈ +200`；低开同幅度 → `−200` | 数值单测 / 手算夹具 |
| R-06-B | 分母改为前收时同一 case 结果不同（能区分两种口径） | 数值单测 |
| R-06-C | 「高开、低开、高开」序列，中间低开值为负而非 0/NaN | 数值单测 |
| R-06-D | 默认参数下第 14 根仍 NaN、第 15 根为首值 | 数值单测 / 夹具 |

**开发动作**：manifest `V08.status=normal`、`specStatus=manualComplete`，`params.period.default` `20 → 14`，`notes` 写「ATR(14)；保留正负号、不筛同向；首值第 15 根；裁定 R-06」。
