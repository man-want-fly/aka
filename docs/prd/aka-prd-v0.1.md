## 0. 文档约定与编号规则

- **Epic**：`E-01` 起，两位数字。
- **Feature**：`F-01.01`，前两位为所属 Epic，后两位为 Epic 内序号。
- **Story**：`S-01.01-01`，前缀与 Feature 一致，末两位为 Feature 内序号。Story 卡后续直接复用本编号，不另起体系。
- **Decision**：`D-01` 起，冻结决策基线。任何变更必须升版本文档，不允许在实现期口头覆盖。
- **Acceptance**：`AC-01.01-01`，前缀与 Feature 一致，末两位为序号；可自动化验收的条目在附录 B 标注为 `auto`，其余为 `manual`。
- **Open Question**：`Q-01` 起，必须给出建议选项与推荐项；未拍板前不得进入开发。
- **引用纪律**：色值、字号、间距、圆角、动效曲线不在本 PRD 重复定义，单一事实源为 `design-spec.html`；技术实现细节不在本 PRD 定义，单一事实源为架构报告 v3。

## 1. 产品合同

### 1.1 目标用户与角色

| 角色 | 画像 | 核心任务（JTBD） | 使用频率 |
| --- | --- | --- | --- |
| 盘后复盘的个人投资者（主） | A 股个人投资者，持有 10–200 只自选，会用 MACD/KDJ/BOLL，但不写代码；只用 macOS | 收盘后用最短路径确认「市场温度 → 自选异动 → 个股结构」，并验证指标参数变化对判断的影响 | 每交易日 1 次，20–60 分钟 |
| 研究型散户 / 量化爱好者（次） | 关注指标公式、参数、复权与单位口径，会对照 TradingView/通达信 | 核对指标读数是否与主流软件一致，理解每个指标的适用边界与陷阱 | 每周 2–5 次，单次 30 分钟以上 |
| 投顾 / 研究员（轻） | 需要快速核对指数、板块与个股图形，用于口头或书面观点 | 在无网络、无账户的环境中快速打开图表、叠加指标、查口径 | 每周 1–3 次 |

### 1.2 触发点与使用场景

1. **收盘后复盘**：15:00 后打开应用，先看指数与板块，再看自选异动，最后逐只打开工作台。
2. **疑问驱动**：盘中或盘后想到某只票，用 `⌘K` 搜索，打开 K 线与多指标叠加，改参数验证。
3. **口径核对**：发现某指标与通达信/ TradingView 不一致，进入指标口径页确认公式、复权、单位与预热。
4. **首次安装 / 换机**：无网络环境下完成样本包生成并进入工作台；或数据损坏后重建。
5. **断网 / 出差**：无网络仍能看图、改参、查口径、看自选与指数。

### 1.3 核心任务链

- **T1 市场扫描**：打开「指数与板块」→ 看 8 个指数、涨跌分布 → 判断当日结构（12 个行业板块 V1 提供，MVP 不含板块层面数据）。
- **T2 自选巡检**：打开「自选」→ 按分组看涨跌幅/成交额/量比 → 定位异动标的。
- **T3 个股分析**：打开工作台 → 切周期/复权 → 主图叠 2 个、副图放 3 个指标 → 改参数验证 → 十字光标读数。
- **T4 口径确认**：从图表 chip 或指标目录进入口径页 → 看公式/参数/适用/陷阱/版本/黄金用例。
- **T5 数据确认**：确认页面顶部「模拟」标识、数据源状态、质量报告与单根 K 线溯源。

### 1.4 完成标志

- 干净 macOS 机器首次安装后，**从点击图标到工作台可交互 ≤ 60 秒**，全程无网络请求。
- 首次安装后 **3 分钟内**完成「打开默认标的 → 改一个指标参数 → 看到曲线变化」。
- 盘后 **5 分钟内**完成「指数板块 → 自选 → 个股 → 改参」闭环，不需要离开应用或登录。
- 断网状态下，行情、自选、工作台、指标目录、口径页、设置、数据状态全部可用。

### 1.5 成功判据

| 判据 | 目标 | 验证方式 |
| --- | --- | --- |
| 首次安装可用率 | 10 名目标用户中 ≥ 8 人无帮助完成首装并打开工作台 |  moderated 可用性测试 |
| 核心任务完成率 | 10 人中 ≥ 8 人在 5 分钟内完成 T1–T3 | 任务脚本 + 观察 |
| 指标一致性 | P0 84 个指标的黄金用例全部在容差内通过 | 引擎测试报告 |
| 口径可解释 | 用户随机抽 10 个指标，能在口径页找到公式、参数、陷阱 | 可用性测试问答 |
| 数据可信 | 任意页面不存在「模拟数据被当作真实数据」的表述 | 文案走查 + 截图审查 |

### 1.6 版本边界一句话

> v0.1 是 **macOS 单机、离线、免费、模拟数据** 的指标分析工作台：提供行情与自选、个股工作台（K 线 + 2 主图叠加 + 3 副图）、指标目录与参数、指标口径页、指数与板块、全局搜索、设置与三主题、数据源状态与模拟标识、首装与样本包回填、空态与错误态；**不联网、不账户、不支付、不交易、不荐股、不画线**。

## 2. 冻结决策基线

> 本章为不可推翻的基线。第 4 章功能规格只能引用，不能重新定义。

### 2.1 平台与技术边界

| ID | 决策 | 影响 / 验收锚点 |
| --- | --- | --- |
| D-01 | 首发仅 macOS 13+（arm64 与 x86_64 双架构）；Tauri 2 + React 18 + TypeScript 前端；Rust 指标引擎；**不使用 Python** | 安装包可启动；引擎进程无 Python 依赖；AC-07.03 |
| D-02 | 本地优先：设置/自选/收藏写入 `state.db`（SQLite）；行情数据写入 `data/sim` 与 `data/real`；无云端、无账户、无控制面 | 断网全功能可用；sim/real 目录物理隔离 |
| D-03 | 日线为最小周期；周线/月线由日线在本地聚合；MVP 不提供分钟线、分时、逐笔 | 周期选择器仅「日/周/月」；无分钟入口 |
| D-04 | 数据层为 `DataProvider` 抽象：4 个必需能力（证券列表、交易日历、日线、复权因子）+ 4 个可选能力（涨跌停标记、指数成分、板块成分、停牌状态）+ 2 个运维能力（健康检查、数据版本）；MVP 只启用 Mock Provider，tushare 仅保留骨架且不可启用 | 数据状态页 Mock 4/4、tushare 0/4；切换按钮不可用 |
| D-05 | 指标注册表共 **105 个 id**；v0.1 发布门槛为 **P0 84 个**可用、可改参、有口径页；P1 21 个为条件交付，未完成不阻塞发布，但不得以「占位行」出现在目录 | 目录行数由已实现注册表派生，不硬编码；每个可见指标都能画线 |
| D-06 | 指标按需计算：不在启动时全量预计算；计算粒度为「当前标的 + 周期 + 复权 + 指标实例参数 + 可见窗口」；参数变更只重算受影响实例 | 平移/缩放/十字光标不触发 IPC 计算；缓存命中率 ≥ 85% |
| D-07 | 6 个一级入口 / 12 个页面：行情、自选、个股工作台、指标目录、指标口径页、指数与板块、搜索（浮层）、设置、数据源状态、模拟数据、空态、错误态 | 侧边栏 6 项；搜索为全局浮层，不占一级入口 |
| D-08 | 图表容量：主图最多 2 个叠加指标；副图最多 3 格（成交量为基础实例，可被替换）；超出必须「替换」而非静默丢弃 | 第 3 个主图叠加被拦截；第 4 个副图弹替换 |
| D-09 | 全部核心任务离线可用；MVP 不发起任何网络请求（含字体、图标、更新检查） | 首装与运行时抓包 0 外部请求 |

### 2.3 数据与指标边界

| ID | 决策 | 影响 / 验收锚点 |
| --- | --- | --- |
| D-15 | 证券代码统一为 `000001.SZ` / `600000.SH` / `000300.SH` 形式；内部成交量单位 **股**，成交额单位 **元**；界面成交量默认展示 **手**（1 手 = 100 股） | 任何指标计算使用股；列表/报价头标注「手」 |
| D-16 | 存储原始价 + 后复权累计因子；前复权在查询时计算，**锚点为最新交易日**；切换复权只影响价格序列与价格型指标 | 不复权/前复权/后复权三选一；缓存键含 `adj_mode` |
| D-17 | MACD 柱按 A 股口径 **HIST = 2 × (DIF − DEA)**；引擎内部保留 `DIF−DEA` 原始值用于校验 | MACD 零点与 DIF/DEA 交叉不变；柱幅为国际口径 2 倍 |
| D-18 | 涨跌停价按交易所规则本地推导：沪深主板 10%、创业板/科创板 20%、北交所 30%；主板/创业板/科创板新股上市前 5 个交易日与北交所首日不设涨跌停；价格四舍五入到 0.01 元。结果标记 `APPROXIMATED`，不作为官方字段。**ST 不进 MVP**，ST 涨跌停规则标 V1，数据契约不含 `is_st` | 涨跌停家数、涨跌停价、一字板识别均引用该推导；质量报告显示「近似」 |
| D-19 | 停牌日保留交易日行：OHLC 取停牌前收盘、成交量 0、`quality_flags=SUSPENDED`；不平滑、不前向填充价格；量类指标在该行返回 NaN | K 线不画实体，仅保留时间轴占位；MFI/OBV 等断线 |
| D-20 | 周/月线由日线聚合：开=区间首个交易日开，高=区间最高，低=区间最低，收=区间最后交易日收，量/额=求和；**先按日复权再聚合**；预热按「周/月根数」计 | 周线 20 根预热 ≈ 100 个交易日；切周期后指标重新计算 |
| D-21 | NaN 不补零、不前向填充；指标线在 NaN 处断开；全 NaN 时面板显示原因而不是空白 | 零成交量 MFI、样本不足的横截面指标均断线 |
| D-22 | 市场广度类指标的分母固定为 **112 只股票**（样本池 120 只证券 = 112 只股票 + 8 个指数，**指数不计入广度**）；不承诺 300 只/全市场 | 页面显示「样本口径 · 112 只（不含 8 个指数）」；六桶之和等于 112 |
| D-23 | v0.1 发布以 P0 84 为门槛；P1 21 个只做条件交付；**目录展示全部 105 条，`planned` 61 条可见、可搜、置灰、不可添加**（点击拒绝并提示），不显示空白占位行；P1 完成则同一版本追加，计数动态派生 | 发布验收只检查 P0；`planned` 行可点击但必须给出「规划中」提示，不得无反应 |
| D-24 | 公式完备度以架构报告 v3 的 **78 完整 / 19 部分 / 8 概念** 为验收分层；其中 T03、T24、F04、F10、F12、F16 六项在本产品补全默认定义后计入「完整」，口径页标注「本产品补全口径」。**该项不需修订** | 目录徽标与口径页一致；设计稿中 72/25/8 的旧计数需同步修正 |

### 2.4 数据口径争议点与产品决策

| 争议 | 候选方案 | 产品决策 | 影响范围 | 验收锚点 |
| --- | --- | --- | --- | --- |
| **复权方式** | 不复权 / 前复权 / 后复权；前复权锚点「最新交易日」或「上市首日」 | 默认**前复权**，锚点**最新交易日**；保留「不复权/后复权」切换；存储原始价+后复权因子，前复权查询时算。理由：与通达信/同花顺默认一致，用户对照成本最低。 | 所有价格型指标（MA/BOLL/MACD/KDJ/RSI/ATR 等）、涨跌幅、报价头；缓存键必须含 `adj_mode`；数据版本更新后前复权历史整体平移，缓存全部失效。 | AC-02.02-03、AC-02.06-04 |
| **成交量单位** | 手 / 股 / 万元 | **内部计算用股，界面展示用手**；成交额用元，界面按万/亿缩写。理由：指标公式（OBV、A/D、CMF、MFI、VWAP、Force Index、RVOL）以股为量纲才与主流实现一致；A 股用户习惯读「手」。 | 量类指标计算与展示；列表「成交量」列头标注「手」；口径页写明「计算单位：股」。 | AC-01.01-03、AC-07.05-02 |
| **MACD 柱** | `DIF−DEA`（国际）或 `2×(DIF−DEA)`（A 股常用） | **采用 `2×(DIF−DEA)`**。理由：目标用户以通达信/同花顺为参照；柱高只影响幅度，不改变零轴与交叉。架构报告 v3 中 `HIST=DIF−DEA` 的恒等式需同步改为 `HIST/2=DIF−DEA`。 | MACD、MACD-V 的柱状展示、Elder Impulse 的柱斜率判断、黄金用例；口径页必须写明「本产品为 A 股 2 倍口径」。 | AC-03.03-02 |
| **涨跌停推导** | 官方字段 / 按板块比例推导 / 不提供 | **按板块比例推导**并按 D-18 处理新股、四舍五入；标记 `APPROXIMATED`。**ST 不进 MVP（标 V1）**。理由：MVP 数据源无官方涨跌停字段，推导可支撑涨跌分布与一字板识别；但必须在质量报告和口径页声明近似。 | 涨跌停家数比（F15）、一字板统计、涨跌分布、缺口统计；不能用于交易决策。 | AC-04.02-03、AC-07.05-01 |
| **停牌/缺行** | 删除行 / 保留行并前向填充 / 保留行不回填 | **保留交易日行，OHLC 取停牌前收盘、量 0、标记 SUSPENDED，不回填价格**；量类指标 NaN。理由：保持时间轴连续，避免指标错位；不伪造成交。 | K 线绘制、MFI/OBV/CMF/VWAP、涨跌家数、指标预热计数。 | AC-02.07-04、AC-07.05-01 |
| **周/月线复权顺序** | 先聚合后复权 / 先复权后聚合 | **先按日复权，再聚合 OHLC**；量和额用原始值求和。理由：除权日在一周中间时，先聚合会产生错误的开收盘关系。 | 周/月线所有价格与指标；预热换算；缓存键含 timeframe。 | AC-02.02-02 |

## 3. 术语表

| 标的 Security | 股票或指数的统一对象；代码为 `000001.SZ` 形式 |

### 4.1 E-01 行情与自选

#### F-01.01 行情列表（P0）

**目标用户与场景**：盘后复盘的个人投资者打开应用后的第一站。需要在 2 秒内看到样本内全部标的的涨跌、成交额、换手、量比，并能按市场分区快速缩小范围。

**功能描述**：展示当前数据集内的全部证券（不虚构全市场覆盖），支持市场分区、列排序、列显隐、加入自选、进入工作台。列表只读，不提供交易、下单、导出。

**交互与状态定义**：
- 默认按「成交额」降序；排序可切换升/降，切换页面后在同一会话内保留。
- 分区：**「全部」为只读总数视图，不是第 5 个分区**；可见分区 4 个：沪 / 深 / 创 / 科。归属映射：`.SH`→沪；`.SZ` 且代码 `00`/`30` 开头→深/创；`688`/`689`→科；`.BJ`→只进入「全部」、不进入任何可见分区。页面断言 `全部 120 = 沪 48 + 深 46 + 创 17 + 科 9 + 北交所 0`；样本出现 `.BJ` 时页头追加「北交所 x 只（仅全部可见）」（见 Q-15）。
- 列：名称、代码、最新价、涨跌幅、涨跌额、成交额、换手率、量比、振幅、自选星标。名称/代码/最新价/涨跌幅常驻；其余可在列设置中显隐。
- 涨跌颜色遵循 D-06 主题语义：默认红涨绿跌，同时用 `+/-` 与 `▲/▼` 双重编码，不允许只靠颜色区分。
- 状态：加载中（仅当本地读取 >120ms 显示骨架）、空数据集、数据集损坏、正常。
- 行点击进入工作台；星标点击加入/移出自选，不触发行跳转。

**数据与字段口径**：
| 字段 | 口径 |
| --- | --- |
| 最新价 | 最新交易日收盘价，按当前默认复权（qfq）展示 |
| 涨跌幅 | `(最新价 / 前收盘 − 1) × 100`，保留 2 位，带符号；**前收盘 = 同一复权序列的前一根收盘**；复权因子或前收缺失时显示「—」，行尾「数据异常」，不按 0 处理 |
| 涨跌额 | `最新价 − 前收盘`，保留 2 位 |
| 成交额 | 最新交易日成交额，元；界面按万/亿缩写，保留 2 位 |
| 换手率 | `成交量 / 流通股本 × 100`，保留 2 位；样本缺流通股本时显示「—」并标注原因 |
| 量比 | `当日成交量 / 过去 5 个交易日平均成交量`，保留 2 位；不足 5 日显示「—」 |
| 振幅 | `(最高 − 最低) / 前收盘 × 100`，保留 2 位 |
| 停牌 | 最新交易日 `SUSPENDED`：价格显示停牌前收盘，涨跌幅显示「—」，行尾「停牌」标签 |

**边界与异常**：
- 数据集为空：显示空态，提供「重建样本包」与「查看数据源状态」，不得显示空白表格。
- 数据集校验失败：进入不可恢复错误态，禁止渲染任何行情行。
- 单只标的数据缺失：该行关键字段显示「—」，不隐藏整行；点击进入工作台时按错误态处理。
- 排序字段全为「—」：保持稳定排序，不随机跳动。

**验收标准**：
- AC-01.01-01 Given 样本包已加载，When 打开行情页，Then 只展示数据集内证券，页头显示「样本 N 只 · 模拟」，不出现虚构的全市场行。
- AC-01.01-02 Given 行情列表，When 点击「沪市/深市/创业板/科创板」，Then 仅保留对应板块证券且计数正确；点击「全部」恢复全量。
- AC-01.01-03 Given 任意数值列，When 点击列头，Then 排序方向切换且数值按 2 位小数/万/亿格式展示；切到其他页面再返回，同一会话内排序与列显隐保留。
- AC-01.01-04 Given 任意一行，When 单击行（非星标区域），Then 打开该标的工作台，报价头与默认图表就绪；返回行情页时分区、排序、滚动位置保留。

**Story**：S-01.01-01、S-01.01-02、S-01.01-03

#### F-01.02 自选与分组（P0）

**目标用户与场景**：用户有 10–200 只关注标的，需要按主题/行业/策略分组，盘后逐组巡检。

**功能描述**：提供「全部」聚合组与最多 20 个自定义分组；单组最多 500 只；支持从行情、工作台、搜索加入自选；支持分组新建、重命名、删除、切换；自选列表复用行情列与排序能力。

**交互与状态定义**：
- 「全部」不可删除、不可重命名，聚合所有自定义分组中的标的；同一标的在多个分组中只出现一次于「全部」。
- 新建分组：点击 `+`，输入名称（1–12 个字符，不允许重名/空白），确认后出现在分组条。
- 重命名：分组右键/更多菜单；重名或空白时禁用确认。
- 删除：若有标的，二次确认「组内 N 只将移入『全部』，不会删除自选」；删除后分组消失，标的不丢失。
- 加入自选：行情行星标、报价头星标、搜索结果星标；重复加入为幂等 no-op。
- 超出 500 只：拒绝并提示「单组上限 500 只，请先清理」；不静默截断。
- 切换分组不重新请求行情，直接读本地快照；若快照过期（数据版本变化）则刷新。
- 状态：空自选、某分组空、正常、数据版本过期。

**数据与字段口径**：
| 字段 | 口径 |
| --- | --- |
| 分组 | `group_id / name / order / created_at`；内置「全部」仅展示与排序，不可删改 |
| 自选项 | `security_code / group_id / added_at / cost_price(P1)`；`UNIQUE(security_code)`（单一归属），`group_id` 可空（NULL = 未分组） |
| 全部组 | 只读派生视图：`COUNT(*)` 全表，不单独存储 items；不承载 `group_id='全部'` 的记录 |
| 排序 | 默认加入时间倒序；可按行情列排序，排序不改变分组存储顺序 |

**边界与异常**：
- 自选中的标的已不在当前数据集：保留记录，行显示「不在当前数据集」，提供移除；不崩溃、不静默删除。
- 分组名含特殊字符：允许中文、字母、数字、空格、`-`、`_`；长度超限时截断提示。
- 数据版本更新导致价格变化：自选列表刷新，但分组与加入时间不变。
- `state.db` 写入失败：当前会话内存生效，顶部提示「自选未保存」，重启后丢失。

**验收标准**：
- AC-01.02-01 Given 某标的不在自选，When 点击星标，Then 星标立即填充，库内新增 1 条 `(security_code, group_id=NULL)` 记录，该标的在「全部」派生视图出现；重启应用后仍在自选。
- AC-01.02-02 Given 自选有分组，When 新建/重命名/删除分组，Then 变更持久化；删除有标的分组时出现二次确认，确认后该组标的 `group_id` 置为 `NULL`（回落未分组，仍在「全部」视图可见），自选总数不变。
- AC-01.02-03 Given 自选总数 500 只，When 加入第 501 只，Then 拒绝并提示「自选上限 500 只，请先移出后再添加」，总数保持 500、不自动淘汰；Given 自定义组已有 20 个，When 新建第 21 个，Then 拒绝并提示「分组上限 20 个，请先删除不用的分组」。
- AC-01.02-04 Given 自选为空，When 打开自选页，Then 显示「还没有自选标的」+「去行情页」可点击动作；不显示空表头、空白行或骨架屏。

**Story**：S-01.02-01、S-01.02-02、S-01.02-03

#### F-01.03 持仓成本与浮动盈亏（P1，条件交付）

**目标用户与场景**：个人投资者在自选列表里记录自己的买入成本，盘后快速看浮盈浮亏，不要求交易记录或组合管理。

**功能描述**：为自选项录入「持仓成本价」，按每股成本计算浮动盈亏率；仅本地存储；不接入券商、不记录买卖、不计算总资产。若 P1 未交付，该列与入口完全不出现。

**交互与状态定义**：
- 在自选行「更多」中录入/修改/清除成本价；输入范围 0.01–99999.99，保留 2 位。
- 浮动盈亏率 = `(最新价 − 成本价) / 成本价 × 100`，保留 2 位，按主题语义着色并带符号。
- 未录入成本：列显示「—」，不显示 0%。
- 清除成本：恢复「—」，不删除自选。
- 该列默认隐藏，用户手动开启后持久化。

**数据与字段口径**：`cost_price` 为每股成本，元；不做数量、手续费、分红、税费；浮动盈亏率不是投资收益承诺。

**边界与异常**：成本价高于/低于现价均正常；停牌时用停牌前收盘计算并标注；标的不在数据集时显示「—」。

**验收标准**：
- AC-01.03-01 Given 自选项成本价 100.00、最新价 110.00，When 查看自选，Then 浮动盈亏率显示 `+10.00%` 且颜色符合当前涨跌语义。
- AC-01.03-02 Given 已录入成本，When 清除成本或重启应用，Then 清除后显示「—」；重启后已保存的成本与列显隐状态保留。

**Story**：S-01.03-01

### 4.2 E-02 个股工作台

#### F-02.01 报价头（P0）

**目标用户与场景**：用户打开个股后，先确认「今天发生了什么」——最新价、涨跌、成交、换手、量比、振幅、涨停价，再决定看什么周期与指标。

**功能描述**：工作台顶部固定报价头，展示标的基础信息、最新交易日行情、模拟标识、自选星标、复权/周期入口。指数使用独立字段集。

**交互与状态定义**：
- 股票字段：名称、代码、板块、`模拟` 标签、最新价、涨跌额、涨跌幅、今开、最高、最低、昨收、成交量（手）、成交额、换手率、量比、振幅、涨停价、跌停价。
- 指数字段：名称、代码、`模拟` 标签、点位、涨跌额、涨跌幅、成交额、样本数；隐藏换手率/量比/涨停价/跌停价。
- 涨跌颜色与符号双重编码；停牌时显示「停牌」标签，最新价标注「停牌前收盘」，涨跌幅「—」。
- 报价头滚动时吸顶；高度不随窗口宽度压缩到遮挡图表。

**数据与字段口径**：
| 字段 | 口径 |
| --- | --- |
| 昨收 | 上一交易日收盘价（原始价口径，不随 qfq 改变） |
| 今开/最高/最低 | 最新交易日原始价 |
| 成交量 | 股 → 手展示（÷100），保留 1 位，万/亿缩写 |
| 成交额 | 元 → 万/亿，保留 2 位 |
| 换手率 | 成交量 / 流通股本 × 100；缺流通股本显示「—」 |
| 量比 | 当日成交量 / 过去 5 日均量；不足 5 日显示「—」 |
| 振幅 | (最高−最低)/昨收×100 |
| 涨停价/跌停价 | 按 D-18 推导，保留 2 位；标记「近似」在口径页说明 |
| 模拟标识 | 来自 `dataset_id` 的 `is_simulated=true`，不可由前端硬编码 |

**边界与异常**：
- 指数不展示股票专属字段，不显示「—」占位。
- 字段缺失：显示「—」并提供 tooltip 原因（缺流通股本/不足 5 日/停牌）。
- 数据集为真实源时隐藏「模拟」，但 MVP 不可达；不得仅靠隐藏标签切换语义。

**验收标准**：
- AC-02.01-01 Given 样本包中的股票，When 打开工作台，Then 报价头展示上述全部股票字段且数值来自最新交易日；「模拟」标签可见。
- AC-02.01-02 Given 指数标的，When 打开工作台，Then 隐藏换手率/量比/涨跌停价，展示点位/涨跌/成交额/样本数。
- AC-02.01-03 Given 最新交易日为停牌，When 打开工作台，Then 显示「停牌」标签与「停牌前收盘」说明，涨跌幅显示「—」，不伪造 0.00%。

**Story**：S-02.01-01

#### F-02.02 主图：周期、复权、图表类型与叠加（P0）

**目标用户与场景**：用户需要在同一张图上切换日/周/月、前复权/不复权/后复权、蜡烛/棒/折线，并叠加最多 2 个主图指标来判断趋势与通道。

**功能描述**：主图渲染价格序列，支持 3 种周期、3 种复权、3 种图表类型、最多 2 个主图叠加指标；切换后保持缩放位置与可见根数（数据不足时自动收缩）。

**交互与状态定义**：
- 默认：日线、前复权、蜡烛图、最近 130 根；缩放范围 30–1000 根，步进 10 根。
- 周期切换：日/周/月；周/月由日线聚合（D-20）；切换后重算所有指标，旧图保留到新结果返回。
- 复权切换：前复权（默认）/不复权/后复权；价格轴与所有价格型指标同步变化；成交量/成交额不变。
- 图表类型：蜡烛/棒/折线；切换不触发指标重算，只换绘制。
- 主图叠加：最多 2 个；已满时添加第 3 个弹出「替换哪一个」对话框；取消不改动。
- 加载中：保留旧曲线并显示右上角局部 spinner；超过 120ms 才显示；不允许整屏白屏。
- 状态：正常、加载中、数据不足、计算失败（保留旧图并标注）。

**数据与字段口径**：
| 项 | 口径 |
| --- | --- |
| 日线 | 来自 `daily_bars`，按 `[open, high, low, close, volume, amount]` |
| 周线 | 周内首个交易日开、最高、最低、最后交易日收；量/额求和；跨周停牌按 D-19 |
| 月线 | 月内首个交易日开、最高、最低、最后交易日收；量/额求和 |
| 复权 | 先按日复权，再聚合；qfq 锚点最新交易日；hfq 用累计因子 |
| 可见根数 | 默认 130；范围 30–1000；不因切周期重置（不足则用可用根数） |
| 主图叠加上限 | 2 个实例；成交量不属于主图叠加 |

**边界与异常**：
- 数据不足 2 根：主图显示「数据不足，至少需要 2 根」，不画线。
- 周/月线不足 1 根：显示空态，提供切回日线。
- 切换过程中数据版本变化：丢弃旧请求结果，按新版本重算。
- 复权因子缺失：回退到不复权并显示可解释提示，不静默混用。

**验收标准**：
- AC-02.02-01 Given 首次打开工作台，When 渲染完成，Then 默认日线/前复权/蜡烛、可见 130 根（数据足够时），页脚显示区间、根数、`qfq`。
- AC-02.02-02 Given 日线数据，When 切到周线，Then 每根周线满足「开=周首日开、高=周内最高、低=周内最低、收=周末日收、量=周内求和」，指标按周根数预热并在 ≤120ms 内更新。
- AC-02.02-03 Given 存在除权日，When 从不复权切到前复权，Then 除权日前后价格连续、指标缓存键变化并重算；任何面板不出现复权/不复权混合序列。
- AC-02.02-04 Given 主图已有 2 个叠加，When 添加第 3 个，Then 弹出替换对话框；选择替换后仅保留 2 个，取消则数量不变。

**Story**：S-02.02-01、S-02.02-02

#### F-02.03 副图：3 格与替换（P0）

**目标用户与场景**：用户需要同时看量能、动量与波动，最多 3 格副图；不希望副图无限堆叠挤压主图。

**功能描述**：副图区固定 3 格；默认「成交量（基础实例）+ MACD + RSI」；每格有独立 Y 轴、指标图例与当前值；支持替换、清空、上下移动；副图高度支持标准/紧凑两档。

**交互与状态定义**：
- 成交量是系统基础实例，不占 105 指标名额，但占用 1 格；可被其他指标替换，替换时提示「成交量将被隐藏」。
- 添加第 4 个副图指标：弹出替换对话框，列出 3 格当前指标；选择后被替换；取消不改动。
- 每格标题显示指标中文名+参数摘要；图例显示各输出线当前值（十字光标处优先，否则最新根）。
- 上下移动改变副图顺序，顺序在当前会话保留。
- 标准高度：主图 60%、3 格各约 13%；紧凑：主图 72%、3 格各约 9%；以设计稿 token 为准。
- 状态：正常、该指标数据不足、该指标全 NaN、计算失败。

**数据与字段口径**：
- 每格绑定 1 个指标实例；实例包含 `indicator_id / params / panel=sub / order`。
- 独立缩放：每格按自身可见数据 min/max 自适应；零轴指标（MACD/ROC 等）固定包含 0。
- 图例数值格式与全局数字设置一致。

**边界与异常**：
- 指标输出线超过 4 条：图例最多显示 4 条，其余折叠为「+N」，不横向溢出。
- 某格指标无定义：显示「停牌无定义/零成交量无定义」，不画 0 线。
- 替换成交量后，报价头的成交量字段仍保留，不受影响。

**验收标准**：
- AC-02.03-01 Given 首次打开工作台，Then 副图恰好 3 格，依次为成交量、MACD、RSI；每格有独立 Y 轴、标题、图例与当前值。
- AC-02.03-02 Given 副图已满 3 格，When 添加第 4 个指标，Then 出现替换对话框；选择一格后该格被替换且总数仍为 3；取消则无变化。
- AC-02.03-03 Given 副图 3 格，When 切换标准/紧凑高度，Then 主图与副图高度按比例变化，图表不重叠、不裁切，设置在同一会话保留。

**Story**：S-02.03-01

#### F-02.04 指标选择抽屉（P0）

**目标用户与场景**：用户需要在 105 条指标（当前可添加 44：`normal` 42 + `beta` 2）中，按分类或关键词快速找到指标并加入主图/副图；也需要管理已选指标的顺序与移除。

**功能描述**：右侧抽屉，双 Tab「指标选择 / 指标参数」。指标选择含 6 个分类 + 搜索 + 收藏筛选；每项展示名称、英文名、面板、预热、完备度徽标、默认参数；支持加入、已添加禁用、收藏、查看口径。

**交互与状态定义**：

#### F-02.05 参数面板（P0）

**目标用户与场景**：研究型用户需要改周期、倍数、阈值，验证指标对同一段行情的敏感度；不能接受输入越界导致崩溃或静默改值。

**功能描述**：为每个已选指标生成参数卡片，字段由 `ParamSpec` 驱动（int/float/enum/bool），支持即时校验、防抖重算、单项重置与全部重置。参数只在当前会话生效（D-14）。

**交互与状态定义**：
- 输入方式：整数用步进器（可键盘输入）；浮点用输入框+单位；枚举用分段按钮；布尔用开关。
- 变更后 150ms 防抖，批量提交受影响实例；只重算该实例，不重算其他指标。
- 越界：字段红框 + 行内文案（最小值/最大值/步进）；不发起计算；「恢复默认」可用。
- 空值/非数字：视为非法，保持上一个有效值并提示；不把 NaN 传给引擎。
- 重置：单卡片「恢复默认」；抽屉底部「全部恢复默认」需二次确认。
- 状态：默认、已修改、非法、计算中、计算失败（保留上一版曲线）。
- 参数范围示例（完整范围以 `ParamSpec` 为准）：MA 周期 2–500；RSI 周期 2–200；BOLL 周期 2–500、倍数 0.5–5.0；MACD 快线 2–200、慢线 3–500、信号 1–100；KDJ 周期 2–200、K 平滑 1–50、D 平滑 1–50。

**数据与字段口径**：
| 字段 | 口径 |
| --- | --- |
| 参数值 | 以注册表默认值为基线；用户值覆盖当前实例 |
| 校验 | 前端 `ParamSpec` 校验 + 引擎二次校验；两层错误码一致 |
| 持久化 | 仅当前会话；重启回默认（D-14） |
| 重算粒度 | 单个指标实例；不因一个指标参数变化重算整图 |

**边界与异常**：
- 多个字段同时非法：每个字段独立报错，不提交任何非法字段；合法字段可单独生效。
- 参数使预热超过可见根数：不报错，转为「数据不足」态。
- 引擎返回越界错误：映射为可纠正错误，恢复上一版曲线，不崩溃。
- 快速连续输入：只提交最后一次有效值。

**验收标准**：
- AC-02.05-01 Given 已选 RSI，Then 参数卡片展示周期步进器，默认 14，范围与步进符合 ParamSpec。
- AC-02.05-02 Given RSI 周期由 14 改为 9，When 停止输入 150ms，Then 只发起一次计算，RSI 曲线在 ≤60ms 内更新，其他指标曲线不闪烁。
- AC-02.05-03 Given 输入 260（超出上限 200），Then 字段红框并显示范围提示，不发起 IPC 计算；点击「恢复默认」回到 14。
- AC-02.05-04 Given 修改过多个指标参数，When 点击「全部恢复默认」并确认，Then 所有实例回到注册表默认值，缓存键恢复，图表重绘。

**Story**：S-02.05-01、S-02.05-02

#### F-02.06 按需计算与缓存（P0）

**目标用户与场景**：用户切换标的/周期/复权/指标/参数时必须快速响应；平移缩放、十字光标不能卡顿；首次冷算可以等待但不能白屏。

**功能描述**：以「标的+周期+复权+指标实例参数+可见窗口+数据版本」为键，按需批量计算当前可见指标；命中缓存直接绘制；未命中时异步计算，保留旧图，超时/取消/过期结果丢弃。

**交互与状态定义**：
- 触发计算：打开标的、切周期、切复权、加指标、改参数、数据版本变化。
- 不触发计算：平移、缩放、十字光标、图例显隐、主题切换、排序。
- 批量：一次请求包含当前所有可见指标实例；不逐个指标串行往返。
- 冷算 >120ms：图表右上角显示局部 spinner + 「计算中」；旧曲线保留；可取消。
- 取消：用户再次切换标的/周期时，自动取消上一次请求；旧结果到达即丢弃，按 `generation_id` 判定。
- 缓存命中：页脚显示「命中 n / 实例 m」；重复操作命中率 ≥85%。
- 缓存范围：当前可见窗口（最多 2000 根）+ 最近一次参数组合；LRU 上限 256MB；数据版本变化全部失效。
- 状态：命中、冷算、计算中、已取消、失败、数据不足。

**数据与字段口径**：
| 项 | 口径 |
| --- | --- |
| 缓存键 | security + timeframe + adj_mode + indicator_id + params + data_version + window |
| 窗口 | 当前可见根数，最多 2000；缩放不重算，仅在窗口超出缓存时补算 |
| 批次 | 一个 batch 包含所有可见实例；返回带 `generation_id` |
| 过期判定 | `generation_id` 小于当前世代即丢弃，不渲染 |
| 缓存统计 | 页脚与关于页可见：命中数、实例数、耗时、缓存占用 |

**边界与异常**：
- 计算失败：保留上一版曲线，面板标注「计算失败」；提供重试与查看错误码。
- 缓存淘汰：不影响正确性；淘汰后重新计算，不显示旧标的数据。
- 数据版本变化：清空缓存并重算；不得命中旧版本。
- 用户快速连续切换 5 只标的：只渲染最后一只，前 4 只结果丢弃，UI 不闪烁。

**验收标准**：
- AC-02.06-01 Given 首次打开某标的，When 渲染完成，Then 可见指标在一次批量请求内返回；3 个副图 × 2000 根冷算 ≤120ms；页脚显示耗时、实例数、命中数。
- AC-02.06-02 Given 相同标的/周期/复权/参数再次打开，Then 指标直接命中缓存，页脚命中数增加；重复 10 次操作命中率 ≥85%。
- AC-02.06-03 Given 图表已渲染，When 平移、缩放或移动十字光标，Then 不发起指标计算 IPC，曲线不闪烁、不重绘为空白。
- AC-02.06-04 Given 切换标的时上一次计算未完成，When 新结果返回前，Then 旧世代结果被丢弃，最终只显示最新标的的曲线与报价头。

**Story**：S-02.06-01、S-02.06-02

#### F-02.07 图表交互与数据不足（P0）

**目标用户与场景**：用户需要自由缩放、平移、用十字光标读取某根 K 线的 OHLCV 与所有指标值；当指标预热不足时，必须知道「为什么没有线」，而不是看到一条假平线。

**功能描述**：提供滚轮/触控板缩放、拖拽平移、十字光标吸附、图例联动、键盘 Esc 关闭；对数据不足、NaN、全 NaN 给出明确状态。

**交互与状态定义**：
- 缩放：以光标位置为锚点，30–1000 根；滚轮/双指；页脚根数实时更新；不触发计算。
- 平移：拖拽或触控板横向滑动；到达数据边界时停止，不回弹到空白。
- 十字光标：吸附最近一根 K 线；显示日期、开/高/低/收、成交量（手）、成交额、涨跌幅，以及所有可见指标的输出值；移出图表区隐藏，Esc 也隐藏。
- 数据不足：面板中央显示「需要 N 根，当前 M 根」+「查看指标口径」；不画线、不画 0 线、不画虚线假数据。
- NaN：线在该点断开；不补零、不前向填充；停牌段显示「停牌无定义」标签。
- 全 NaN：该面板显示原因与「更换指标/查看口径」，不留空白格。
- 状态：正常、数据不足、部分 NaN、全 NaN、计算失败。

**数据与字段口径**：
| 项 | 口径 |
| --- | --- |
| 可见根数 | 30–1000；默认 130；页脚展示 |
| 十字光标取值 | 最近一根的原始 OHLC + 当前复权后的指标输出 |
| 数据不足判定 | 有效根数 < 指标 `warmup`；有效根数不含 NaN 行 |
| 停牌行 | 保留时间轴；量类指标 NaN；价格类以前收盘参与 |
| 指标值精度 | 价格 2 位、百分比 2 位、量 1 位/万/亿；图表轴按量级自适应 |

**边界与异常**：
- 数据只有 1 根：主图仍绘制 1 根，指标全部数据不足。
- 全 NaN 指标（如零成交量 MFI）：不把 NaN 当 0；图例显示「—」。
- 缩放至极小/极大：夹在 30/1000，不出现空白或重复 K 线。
- 十字光标在停牌行：量显示 0、量类指标「—」，价格显示停牌前收盘。

**验收标准**：
- AC-02.07-01 Given 图表已渲染，When 滚轮缩放或拖拽平移，Then 可见根数在 30–1000 内变化，页脚同步更新，且无指标计算请求、无闪烁。
- AC-02.07-02 Given 十字光标位于某根 K 线，Then 显示该日 OHLCV、成交额、涨跌幅与所有可见指标值；移出图表或按 Esc 后隐藏。
- AC-02.07-03 Given BOLL(20) 只有 8 根有效数据，Then 该面板显示「需要 20 根，当前 8 根」，不画线；补足数据后无需手动刷新即出现曲线。
- AC-02.07-04 Given 停牌段零成交量，When 查看 MFI，Then 对应点为 NaN 且线断开，图例显示「—」并标注「停牌无定义」；不显示 0。

**Story**：S-02.07-01、S-02.07-02

#### F-02.08 计算元信息与溯源（P0）

**目标用户与场景**：研究型用户需要确认「这条线是谁算的、用哪版数据、耗时多少、命中缓存没有」，以及单根 K 线来自哪个批次。

**功能描述**：图表页脚常驻计算元信息；点击/悬停任意 K 线弹出溯源卡，展示 provider、批次、时间戳、数据集、复权、质量标记。支持复制错误码/溯源文本。

**数据与字段口径**：

| batch | 生成批次 id |
| ts | 数据生成/拉取时间戳（ISO 8601） |

**边界与异常**：溯源缺失视为数据质量缺陷，记录错误码；不显示空白浮层；不影响曲线渲染。

**验收标准**：

### 4.3 E-03 指标目录与口径

#### F-03.01 指标目录（P0）

**目标用户与场景**：用户需要在一个可信的目录里浏览所有可用指标，按分类/关键词找到目标，理解完备度与数据要求，再决定加入图表或收藏。

**功能描述**：展示注册表全部 105 条（其中可添加 44 条），按 6 类分组，支持搜索、收藏筛选、徽标、加入图表、进入口径页。目录行数与分类计数由注册表 `status`/`priority`/`completeness`/`specStatus` 动态派生，不硬编码 105，也不把 P0 84 当作可添加数。

**交互与状态定义**：
- 分类计数：105 条口径下为趋势 24、动量 26、波动 10、量能 15、统计 14、广度 16；P0/P1 计数单独展示（P0 84 / P1 21），P0 全量实现后「可添加」由 44 升至 84。
- 每行：id、中文名、英文名、分类、面板、预热、默认参数、完备度、溯源、数据要求、收藏星、加入、口径。
- 完备度 `completeness`：`完整` / `部分（本产品口径）` / `beta`（概念级）；**内部验收分层，用户不可见，不渲染徽标**；六项补全项标注「本产品补全口径」。
- 溯源 `specStatus`：`manualComplete` / `partial`（手册部分覆盖）/ `productDefined`（产品自研）；**非 `manualComplete` 即显示「口径待定」徽标（不限 `status`，共 15 条）**。
- 搜索：中文/英文/id/口径关键词；≤100ms；清空恢复；无结果空态。
- 加入：若当前有工作台，按面板加入；容量满进入替换；若无工作台，提示先选标的并跳转行情。
- 收藏筛选：只显示已收藏；与搜索可叠加。
- 状态：正常、搜索空、收藏空、加入受限（数据要求不满足）。

**数据与字段口径**：
| 字段 | 口径 |
| --- | --- |
| 目录数量 | 注册表全量 105 行（`status` 分布 61/42/2）；可添加 = `normal` + `beta` = 44 = 42 + 2 |
| 分类计数 | 按 `category` 动态统计，不写死；105 条口径下为 24/26/10/15/14/16 |
| 完备度 | 78 完整 / 19 部分 / 8 beta（概念级）；六项补全计入完整（D-24） |
| 溯源 | `manualComplete` 88 / `partial` 13 / `productDefined` 4；「口径待定」= 非 `manualComplete`（**不限 `status`**，15 条 = partial 11 + productDefined 4，含已实现 T16/T19）（D-24a） |
| 数据要求 | `adj_required / cross_section / benchmark / sample_pool` |
| 默认参数 | 注册表 `default_params`；参数面板同源 |

**边界与异常**：
- P1 未实现：目录**可见（置灰）**、可搜到、不可添加，点击提示「该指标规划中，本期未开放」；不显示空白占位行。
- `beta` 与 `口径待定` 并存（如 T19，`status=beta` 且 `specStatus=partial`）：两个徽标同时出现，hover 文案分别为「口径未获外部对照」与「公式依据待核定」，不得合成一句；M22（`planned`+`productDefined`）只出现「规划中」「口径待定」两徽标，**不出现 `beta`**。
- 指标缺口径页：发布阻断，目录该行标注错误并禁止加入。
- 搜索特殊字符/空格：trim 后匹配；无结果不报错。
- 目录与抽屉同源：同一指标在两处的名称、徽标、参数一致。

**验收标准**：
- AC-03.01-01 Given GA 版本，Then 目录展示注册表全量 105 行（可添加 44 = `normal` 42 + `beta` 2，`planned` 61 行可见、可搜、置灰且不可添加），无空白占位行、无重复 id；`normal`/`beta` 行点击「加入」后能在样本数据上画出至少一条线。
- AC-03.01-02 Given 6 个分类，When 逐个筛选，Then 各分类渲染行数之和等于目录总数 105（趋势 24 / 动量 26 / 波动 10 / 量能 15 / 统计 14 / 广度 16）；同屏页头 P0/P1 分列为 84/21，P0 分类分布 21/17/9/12/10/15 之和 84。
- AC-03.01-03 Given 搜索「量比」，Then 命中 D11 RVOL；搜索「RSI」命中 M01；搜索「除权」命中带复权口径关键词的指标；清空后恢复全部。
- AC-03.01-04 Given 每个指标行，Then 展示溯源徽标（`specStatus`）、面板、预热、默认参数、数据要求；**`completeness` 不渲染任何徽标（用户不可见）**；六项补全指标显示「本产品补全口径」。`beta` 只由 `status=beta` 触发（T16/T19），`口径待定` 由 `specStatus≠manualComplete` 触发（15 条），两轴独立、互不替代；T19 同时出现「beta」「口径待定」两徽标，M22 只出现「规划中」「口径待定」。
- AC-03.01-05 Given 无打开标的时点击「加入」，Then 提示先选择标的并跳转行情；有标的时按面板加入或进入替换流程。

**Story**：S-03.01-01、S-03.01-02、S-03.01-03、S-03.01-04

#### F-03.02 指标收藏（P0）

**功能描述**：在目录、抽屉、口径页均可收藏/取消收藏；首次安装预置 8 个默认收藏（`T01` SMA、`T02` EMA、`T09` BOLL、`M06` MACD、`M01` RSI、`M02` KDJ、`V01` ATR、`M05` CCI，均为注册表 `status=normal` 的真 id）；收藏只影响排序与筛选，不改变默认图表组合。

#### F-03.03 指标口径页（P0）

**目标用户与场景**：用户发现指标与通达信/TradingView 不一致，或想理解适用边界与陷阱；需要一页说清「公式、参数、适用、陷阱」，并能看到实现版本与验证用例。

**功能描述**：每个已实现指标一页，固定四段：公式、参数、适用、陷阱；顶部展示 id/名称/分类/面板/预热/完备度/数据要求；底部展示实现版本、黄金用例来源与容差；beta/部分口径有显著横幅。

**交互与状态定义**：
- 四段内容不可为空；缺一段即发布阻断（V7 子集）。
- 部分口径横幅：「本产品口径，可能与 TradingView 不同」；beta 横幅：「概念口径，禁止用于默认组合」。
- 黄金用例：来源（如 TA-Lib 0.4.0 / 内部参考实现）+ 容差（价格 1e-6、比率 1e-4）；无来源不得写「已验证」。
- 深链：目录行、工作台 chip、图例标题均可进入；返回时保留图表状态（标的/周期/复权/参数/缩放）。
- 状态：完整、部分口径、beta、缺失（阻断）、版本过期（提示）。

**数据与字段口径**：
| 段 | 必含内容 |
| --- | --- |
| 公式 | 输入、输出、递推/窗口、初始化、NaN 规则；MACD 必写 `HIST=2×(DIF−DEA)` |
| 参数 | 名称、类型、默认值、范围、步进、影响 |
| 适用 | 适用市场/周期/场景，A 股注意事项（复权、手/股、停牌、涨跌停） |
| 陷阱 | 至少 2 条可验证的误用/边界（如零成交量、样本不足、未来函数） |

**边界与异常**：
- 缺口径页：目录与图表禁止加入，错误码 `E_SPEC_MISSING`。
- 版本不一致：口径页显示实现版本与文档版本；不一致时提示「口径需更新」，不静默。
- 长文本：滚动阅读，不截断；不提供编辑。

**验收标准**：
- AC-03.03-01 Given 任意已实现指标，When 打开口径页，Then 四段内容均非空，且公式段包含输入/输出/NaN 规则。
- AC-03.03-02 Given MACD 口径页，Then 明确写出 `HIST = 2 × (DIF − DEA)`，并给出黄金用例来源与容差；不得只写「与主流一致」。
- AC-03.03-03 Given 从工作台 chip 进入口径页，When 返回，Then 标的、周期、复权、参数、缩放位置全部保留。
- AC-03.03-04 Given GA 版本，Then 全部 P0 已实现指标均有口径页，0 个占位/「暂无」；缺失即发布阻断。

**Story**：S-03.03-01、S-03.03-02、S-03.03-03

#### F-03.04 指标数值内核（B1 底座）（P0）

**目标用户与场景**：指标与行情软件逐根对照时出现差异；用户需要确认「公式、种子、预热、首值、NaN 与容差」是可复现的，而不是口头承诺。本 Feature 定义 B1 首批 11 个已实现指标（T01–T05、T19–T22、E13、M06）的数值口径与验收标准；**新增 Story 一律未结项**。

**功能描述**：每条指标由「公式 + 种子/初始化 + `first_value` 位置 + 产品 `min_bars` + 单位与小数 + 容差」六项定死；黄金夹具由**不调用引擎**的独立参考实现生成；数值层证据与渲染层证据分离，禁止互相替代。

**交互与状态定义**：
- 无独立页面；本期 UI 暴露 T01/T02/T03（主图）与 M06（副图），T04/T05、T19–T22、E13 已实现但未进 UI。
- 数值层断言以 `[数据层]` 取证（黄金夹具 + 手算对拍），渲染层断言单列 `[渲染层]`，S2 前端补齐。
- 未暴露指标的渲染层 AC 一律登记未结项，不得计入结项。
- **结项状态（2026-11-06 修订）**：本 Feature 下 `S-03.04-01 / 02 / 03` 一律为**整卡未结项**。三态为：数值层证据已具备（`[数据层]`，未经 QA 签认）、渲染层未做（`TD-B1-02`）、口径页未做（`TD-B1-03`）。是否结项随 S2 由 QA 统一签认，PRD 不预设结论。

**数据与字段口径**：
| 指标族 | 公式 | 引擎首值 | 产品 `min_bars` | 单位 / 小数 |
| --- | --- | --- | --- | --- |
| SMA / EMA / WMA / DEMA / TEMA（T01–T05） | 见 S-03.04-01 字段表 | 20 / 20 / 20 / 60 / 90 | 20 / 60 / 20 / 60 / 90 | 元 / 2 位 |
| MACD（M06） | `DIF=EMA12−EMA26`；`DEA=EMA(DIF,9)`；`HIST=2×(DIF−DEA)` | DIF 26；DEA / HIST 34 | 34 | 元 / 2 位 |
| OLS 族（T19–T22） | `x=0..N−1`；`b=Sxy/Sxx`；`a=ȳ−b·x̄`；`T19=a+b·(N−1)`；`R²=Sxy²/(Sxx·Syy)` | 20 | 20 | 元 / 元 / 无量纲 / 元每根 |

| 板块涨跌幅（V1） | 成分股区间涨跌幅等权平均；不按市值加权（MVP 无可靠流通市值） |
| 板块数量（V1） | 12；由 manifest/行业映射决定 |
| 停牌 | 单独桶；不计入涨/跌/平 |

**边界与异常**：
- 样本池与页面宣称不一致：以 manifest 为准，页面显示「样本口径 · 112 只（不含 8 个指数）」；禁止写 300/5,286。
- 板块成分为空（V1）：该板块行显示「样本缺失」，不隐藏整个板块区。
- 涨跌停价推导失败（缺昨收/缺板块规则）：该股计入「上涨/下跌」，不计入涨跌停，并记录质量标记。
- 数据不足 20 日：20 日区间列「—」，不缩短。

**验收标准**：
- AC-04.02-01 Given 样本池 112 只股票，Then 分布六个桶数量之和严格等于 112；页面标注「样本口径 · 112 只（不含 8 个指数）」，指数不进入任何桶。
- AC-04.02-02 **V1（ST 延后）**：ST 涨停子计数随 ST 一并延后至 V1，本期不验收。
- AC-04.02-03 Given 涨跌停推导，Then 页面与质量报告均标「近似」；主板/创业板/科创板/北交所四类比例分别为 10%/20%/20%/30%。
- AC-04.02-04 **V1（产品裁定；移出 MVP 验收）**：12 个行业板块按等权区间涨跌幅降序，数值与成分股平均一致（允许 0.01% 舍入）。恢复时须先补 `sector_members` 才能判定。
- AC-04.02-05 **V1（产品裁定；移出 MVP 验收）**：某板块成分为空时显示「样本缺失」，其余板块正常展示。

**Story**：S-04.02-01、S-04.02-02

### 4.5 E-05 搜索

#### F-05.01 全局搜索（P0）

**目标用户与场景**：用户在任意页面想到一个代码、名称或拼音首字母，希望 1 次按键、1 个输入框、100ms 内跳到工作台，不离开当前上下文。

**功能描述**：全局搜索浮层，支持证券代码（带/不带交易所后缀）、中文名称子串、拼音首字母；结果最多 20 条；支持键盘上下选择与 Enter 打开；不搜索指标、不搜索新闻/公告。

**交互与状态定义**：
- 唤起：任意页面按 `⌘K`；点击顶栏搜索按钮也可。
- 输入：trim 后至少 1 个字符；不区分大小写；中文/英文/数字均可。
- 结果：名称、代码、板块、最新价、涨跌幅、`模拟` 标签、类型（股票/指数）；匹配片段高亮。
- 键盘：`↑/↓` 移动选中，`Enter` 打开，`Esc` 关闭并清空；鼠标单击打开。
- 空查询：显示「最近查看」最多 5 条 + 指数快捷入口；最近查看仅本地。
- 无结果：保留查询词，显示「未找到」+「清空」+「去行情浏览」；不显示骨架屏。
- 状态：空闲（最近）、输入中、有结果、无结果、数据未加载（错误态）。

**数据与字段口径**：
| 项 | 口径 |
| --- | --- |
| 搜索范围 | 当前数据集内的股票与指数；不含已退市/不在数据集的标的 |
| 代码匹配 | `300750` 与 `300750.SZ` 均可命中；后缀不区分大小写 |
| 名称匹配 | 中文子串；不做同音字/模糊纠错 |
| 拼音匹配 | 首字母串（如 `ndsd` 命中宁德时代）；不做全拼 |
| 排序 | 精确代码 > 代码前缀 > 名称前缀 > 名称子串 > 拼音；同分按成交额降序 |
| 延迟 | 本地索引 ≤100ms；输入防抖 80ms |
| 结果上限 | 20 条；超出提示「仅显示前 20 条」 |

**边界与异常**：
- 特殊字符/空格：trim 后匹配；无结果不报错。
- 同一代码跨市场：以 `code.suffix` 唯一匹配，结果展示交易所。
- 停牌标的：正常出现在结果，标注「停牌」。
- 数据未加载：搜索不可用，显示数据集错误态，不返回空结果误导。

**验收标准**：
- AC-05.01-01 Given 任意页面，When 按 `⌘K` 并输入 `300750`/`宁德`/`ndsd`，Then 均在 ≤100ms 内返回同一标的，结果含代码、名称、板块、模拟标签。
- AC-05.01-02 Given 搜索结果，When 按 `↓` 选中第二条并按 `Enter`，Then 打开该标的工作台；按 `Esc` 关闭浮层并清空输入。
- AC-05.01-03 Given 输入不存在的关键词，Then 保留查询词并显示「未找到」与两个动作，不显示骨架屏，不返回无关结果。
- AC-05.01-04 Given 断网，When 搜索样本内标的，Then 仍可用；搜索不发起任何网络请求。

**Story**：S-05.01-01、S-05.01-02

### 4.6 E-06 设置与主题

#### F-06.01 主题与配色（P0）

**目标用户与场景**：用户在不同环境光下使用，需要深色/浅色/跟随系统；A 股用户默认红涨绿跌，部分用户习惯国际绿涨红跌。

**交互与状态定义**：

- 配色：红涨绿跌（默认）/绿涨红跌；切换只交换语义色，不改变数值、符号、箭头。

- 状态：已保存、保存失败（当前会话仍生效 + toast）、系统外观变化。

**数据与字段口径**：
| 项 | 口径 |
| --- | --- |
| theme_mode | `dark / light / system`，默认 `dark` |
| color_direction | `cn / intl`，默认 `cn` |
| 语义色 | 上涨/下跌/平盘/强调/背景/边框/文字层级；色值锚定 `design-spec.html` |
| 双重编码 | 涨跌必须同时有符号与箭头，不能只靠颜色 |

**边界与异常**：

**验收标准**：

- AC-06.01-02 Given 默认红涨绿跌，When 切到绿涨红跌，Then 涨跌颜色互换，但 `+/-`、`▲/▼` 与数值不变。
- AC-06.01-03 Given 任意主题，Then 图表背景/网格/文字/涨跌色均来自设计 token；不存在白底黑字与深色页面混用的硬编码色。

**Story**：S-06.01-01、S-06.01-02

### 4.7 E-07 数据源与模拟环境

#### F-07.01 数据源状态（P0）

**目标用户与场景**：用户需要知道「现在用的是假数据还是真数据、能力覆盖多少、是否健康」，以及为什么不能切到 tushare。

**功能描述**：数据源状态页展示 Mock 与 tushare 两张能力卡、健康检查、覆盖能力、限制与切换成本。MVP 只启用 Mock；tushare 置灰不可切换。

**交互与状态定义**：
- Mock 卡：状态「已启用」；必需 4 项（证券列表、交易日历、日线、复权因子）全绿；可选 3 项（涨跌停标记、指数成分、停牌状态）按实际能力显示；板块成分（`sector_members`）随 12 行业板块降级 V1，不作为 MVP 能力；运维 2 项（健康检查、数据版本）。
- tushare 卡：状态「未启用 / 骨架」；0/4；展示 token 要求、限流/积分限制、字段映射差异、切换成本；所有按钮禁用并给出原因。
- 健康检查：点击后本地检查数据集完整性/可读性/版本，≤1s 返回；显示时间戳与结果；失败进入可重试错误。
- 切换数据源：MVP 无可用切换；按钮禁用，hover 说明「真实源接入不在 v0.1 范围」。
- 状态：检查中、健康、降级（部分能力缺失）、失败、未启用。

**数据与字段口径**：
| 项 | 口径 |
| --- | --- |
| Provider 能力 | `securities / trade_calendar / daily_bars / adj_factors` 为必需；`limit_flags / index_members / sector_members / suspend_status` 为可选 |
| 数据版本 | `dataset_id / generated_at / row_count / coverage_start / coverage_end / sha256` |
| 健康检查 | 只读本地数据，不联网；结果含检查项、耗时、错误码 |
| 真实源状态 | 0/4，未启用；不得显示「已连接」 |

**边界与异常**：
- Mock 数据缺失：健康检查失败，提供重建；不静默回退到空数据。
- tushare 卡片：不得出现可点击的「启用」或虚假进度。
- 健康检查与页面其他请求并发：不阻塞主界面，不重复弹窗。

**验收标准**：
- AC-07.01-01 Given 数据源状态页，Then Mock 显示已启用、4/4 必需能力、可选能力状态与数据版本；tushare 显示 0/4、未启用与切换成本。
- AC-07.01-02 Given 点击「健康检查」，Then ≤1 秒返回检查项、耗时与结果时间戳；失败显示错误码与重试，不发起网络请求。
- AC-07.01-03 Given tushare 卡片，Then 所有启用/连接控件不可点击并说明原因；页面无「已连接/同步中」等误导状态。

**Story**：S-07.01-01、S-07.01-02

#### F-07.02 模拟标识与隔离（P0）

**目标用户与场景**：用户必须一眼分辨数据性质，避免把模拟走势当作真实行情；维护者需要确保模拟数据不会污染真实数据。

**功能描述**：全局状态条、行情页头、报价头、指数页、质量报告统一展示「模拟 / 样本口径」；`data/sim` 与 `data/real` 物理隔离；`dataset_id` 参与缓存与溯源。

**交互与状态定义**：
- 全局状态条常驻底部或顶部（按设计稿）：「模拟数据 · 仅用于功能验证」；不可关闭。
- 行情页头显示「样本 N 只 · 模拟」；报价头显示 `模拟` pill；指数页显示「样本口径」。
- 真实数据接入后：标识由 `is_simulated` 驱动，隐藏「模拟」，但 MVP 不可达。
- 隔离：重建/删除只作用于 `data/sim`；`data/real` 只读；任何缓存键必须含 `dataset_id`。
- 状态：模拟、真实（未来）、数据集缺失。

**数据与字段口径**：
| 项 | 口径 |
| --- | --- |
| is_simulated | 数据集级布尔，写入 manifest 与每根 K 线 |
| dataset_id | 含 `sim-` / `real-` 前缀 |
| 缓存键 | 必含 `dataset_id`，禁止跨数据集命中 |
| 目录 | `data/sim/*`、`data/real/*`；无写入交叉 |

**边界与异常**：
- 模拟数据缺失：阻断行情与工作台，进入首装/重建，不显示空图表冒充。
- 数据源切换（未来）：必须清空缓存并提示；MVP 不提供。
- 截图/系统分享由 OS 完成，应用不额外生成带水印图片；页面内标识必须常驻。

**验收标准**：
- AC-07.02-01 Given 任意行情/工作台/指数/质量页面，Then 至少一处「模拟」或「样本口径」可见；页面不存在「真实行情」表述。
- AC-07.02-02 Given `data/real` 中存在哨兵文件，When 执行样本包重建，Then 哨兵文件内容与 mtime 不变，重建只影响 `data/sim`。
- AC-07.02-03 Given 两个不同 `dataset_id` 的数据集，When 切换/重建后打开同一标的，Then 缓存不跨数据集命中，图表与溯源均指向当前 `dataset_id`。

**Story**：S-07.02-01、S-07.02-02

#### F-07.03 首装与样本包（P0）

**目标用户与场景**：新用户第一次打开应用，无账户、无网络，需要在 1 分钟内得到可用的样本数据；或数据损坏后需要可恢复地重建。

**功能描述**：首装向导 5 步，生成确定性样本包（120 只证券 × 520 个交易日，共 62,400 行，seed 固定），完成校验、预热并进入工作台；提供样本包元信息、重建、校验失败处理。

**交互与状态定义**：
- 步骤：① 初始化 `state.db`；② 生成样本包（证券/日历/日线/复权因子）；③ 校验 manifest 与 sha256；④ 预热最近 2000 根；⑤ 进入工作台（有自选进自选第一只，无自选进 manifest 第一只）。
- 进度：每步显示名称、状态、耗时、进度条；总耗时目标 ≤60s；无网络。
- 中断：用户退出/崩溃后，下次启动检测未完成标记，显示「上次未完成」并从步骤 ② 重新开始；不加载半成品。
- 元信息：`dataset_id / generator_version / seed / security_count / coverage_start / coverage_end / row_count / size_bytes / sha256`；UI 显示实际值，不硬编码。
- 重建：设置/模拟数据页入口；二次确认，明确「删除并重建 `data/sim` 的 N 只 × 区间样本；`data/real` 不受影响」；确认后进度页；取消无变化。
- 校验失败：拒绝加载，显示不可恢复错误，提供重建/诊断/只读。
- 状态：未开始、进行中、已完成、失败、已中断、需重建。

**数据与字段口径**：
| 项 | 口径 |
| --- | --- |
| 样本证券 | 120 只（含 8 个指数；具体清单由 manifest 定义） |
| 覆盖区间 | MVP 为 `2023-01-02 ~ 2024-12-27`（520 个工作日）；UI 只显示 manifest 实际值；**对外不做数据范围承诺** |
| 生成器 | 确定性；同一 seed + 版本 = 同一数据集（sha256 一致） |
| 行数/体积 | 由 manifest 提供；MVP 行数 **62,400 = 120 × 520**；UI 不写死 57,840/18.7MB |
| 复权因子 | 样本内包含除权事件，保证 qfq/hfq 可验证 |
| 网络 | 全程 0 请求 |

**边界与异常**：
- 磁盘不足：步骤 ② 前检查空间，失败提示所需/可用空间，不留半成品。
- 生成器崩溃：标记未完成；下次重启重试；连续 2 次失败提供诊断包。
- sha256 不一致：拒绝加载；错误页显示期望/实际摘要。
- 重建时正在看图：阻断图表交互，显示进度；完成后自动打开原标的（若仍存在）。
- 用户手动删除 `data/sim`：下次启动进入首装，不崩溃。

**验收标准**：
- AC-07.03-01 Given 干净机器与参考机（M1/16GB），When 首次启动，Then 5 个步骤可见，从点击图标到工作台可交互 ≤60 秒，全程 0 网络请求。
- AC-07.03-02 Given 首装进行中，When 强制退出后再次启动，Then 显示「上次未完成」并从生成步骤重试；不加载半成品数据。
- AC-07.03-03 Given 首装完成，Then 模拟数据页展示 manifest 的 9 个字段（含实际区间、行数、体积、sha256），且数值与数据目录一致。
- AC-07.03-04 Given 点击重建并确认，Then 只删除/重写 `data/sim`；`data/real` 哨兵文件不变；取消则无任何写入。
- AC-07.03-05 Given sha256 不一致，Then 拒绝加载并显示不可恢复错误（期望/实际摘要、trace id）与「重建/诊断/只读」三个动作。

**Story**：S-07.03-01、S-07.03-02、S-07.03-03

#### F-07.04 真实数据回填（P0，仅展示未启用）

**目标用户与场景**：用户想知道「什么时候能用真实数据、要多久、要什么条件」，避免误以为当前可以回填。

**功能描述**：模拟数据页展示真实数据回填计划卡：60 日快速包、3 年全量包、复权因子合并、请求量、预计耗时、前置条件；全部操作禁用，并给出明确原因。

**交互与状态定义**：
- 卡片字段：方案名、覆盖区间、预计请求数、预计耗时、依赖（token/积分/网络）、状态「未启用」。
- 操作：开始回填/暂停/继续均禁用；点击只显示原因 toast，不产生任务、不显示进度。
- 文案：说明真实源接入不在 v0.1；不得写「即将上线」或倒计时。
- 状态：未启用、未来可用（不可达）。

**数据与字段口径**：
| 方案 | 覆盖 | 预计请求 | 预计耗时 |
| --- | --- | --- | --- |
| 60 日快速包 | 最近 60 个交易日 | 124 次 | 约 2.2 小时（限流下） |
| 3 年全量包 | 近 3 年 | 1,452 次 | 约 26.2 小时（限流下） |
| 复权因子 | 与上述区间一致 | 合并在内 | 合并在内 |

**边界与异常**：
- 用户点击禁用按钮：toast 说明原因；不记录任务、不写数据库。
- 断网/无 token：不影响卡片展示；MVP 不检查 token。
- 页面不得展示虚假进度或「已完成 0%」以外的执行态。

**验收标准**：
- AC-07.04-01 Given 模拟数据页，Then 展示 60 日/3 年两套方案及请求数、预计耗时、前置条件；状态为「未启用」。
- AC-07.04-02 Given 点击任一被禁用操作，Then 仅显示原因提示，不创建任务、不写库、不出现进度条。

**Story**：S-07.04-01

#### F-07.05 质量报告与溯源（P0）

**目标用户与场景**：研究型用户与支持人员需要知道数据有哪些已知问题（除权、停牌、零量、价格异常、复权覆盖），并能追到单根 K 线的来源。

**功能描述**：数据源状态页展示 6 项质量检查，包含数量、占比、处理方式、状态；工作台提供单根 K 线溯源（与 F-02.08 同一组件）。质量报告可刷新，显示生成时间与是否过期。

**交互与状态定义**：
- 6 项检查：缺失交易日、除权事件、停牌日、零成交量、价格异常（高低/负值/跳变）、复权因子覆盖。
- 每项列：检查名、命中数量、占比、处理方式（保留/标记/剔除? MVP 不剔除）、状态（通过/警告/失败）。
- 标记：`EX_RIGHTS / SUSPENDED / APPROXIMATED / SAMPLE`；不得静默修正。
- 刷新：点击重新扫描；显示耗时与生成时间；扫描中不阻塞其他页面。
- 过期：数据版本变化后旧报告标「已过期」，保留上次结果并提示刷新。
- 溯源：从报告中点示例进入工作台并定位该 K 线；或在工作台直接点 K 线。
- 状态：最新、扫描中、过期、失败（显示上次成功结果 + 时间）。

**数据与字段口径**：
| 检查 | 判定 | 处理 |
| --- | --- | --- |
| 缺失交易日 | 日历有、数据无 | 保留占位/标记 MISSING，不插值 |
| 除权事件 | 复权因子变化日 | 标记 EX_RIGHTS，价格按 D-16 处理 |
| 停牌日 | 成交量 0 + 停牌状态 | 标记 SUSPENDED，OHLC=前收，量=0 |
| 零成交量 | volume=0 非停牌 | 标记 ZERO_VOLUME，量类指标 NaN |
| 价格异常 | low>high、负价、单日跳变超阈值 | 标记 PRICE_ANOMALY，展示不修正 |
| 复权覆盖 | 复权因子缺失区间 | 标记 ADJ_GAP，回退不复权并提示 |

**边界与异常**：
- 扫描失败：保留上次成功报告并标过期时间；不显示「0 问题」。
- 质量报告与图表数据版本不一致：提示过期，避免误读。
- 单根溯源缺失：标 `E_PROVENANCE_MISSING`，不显示空卡。
- 真实源未启用：报告只针对当前模拟数据集，标题必须含数据集 id。

**验收标准**：
- AC-07.05-01 Given 质量报告，Then 6 项检查均展示数量、占比、处理方式与状态；有命中时显示对应标记；无命中显示「通过」。
- AC-07.05-02 Given 任意 K 线，When 打开溯源，Then 展示 provider/batch/ts/dataset_id/adj_mode/quality_flags；缺失字段显示「缺失」。
- AC-07.05-03 Given 数据版本变化，Then 质量报告标「已过期」并保留上次结果与生成时间；刷新后更新，不静默显示旧报告为最新。

**Story**：S-07.05-01、S-07.05-02

### 4.8 E-08 空态与错误态

#### F-08.01 空态（P0）

**目标用户与场景**：新用户、搜索失败、指标预热不足、分组为空时，用户需要知道「为什么空」与「下一步做什么」，而不是看到空白面板或假数据。

**功能描述**：四类空态：自选空、搜索/指标无结果、数据不足、分组空；统一规则：说明原因 + 至少一个下一步动作 + 不使用骨架屏（仅首次加载可用骨架）。

**交互与状态定义**：
- 自选空（含「未分组」视图为空）：文案「还没有自选标的」+「去行情挑选」+「搜索标的」。
- 搜索无结果：保留查询词 +「清空」+「去行情浏览」；不自动清空。
- 指标搜索无结果：显示「0 个匹配」+「查看全部指标」；保留查询。
- 分组空：文案「这个分组还没有标的」+「去行情页加星」；组名固定为「未分组」（**不带括号**，不得写成「（未分组）」或「『全部』视图（未分组）」）。
- 数据不足：面板内「需要 N 根，当前 M 根」+「查看口径」+「重建样本包」（模拟环境）。
- 空态不显示 0、不显示假曲线、不显示「暂无数据」孤零零四个字。
- 状态：空、加载中（骨架）、正常。

**数据与字段口径**：
| 空态 | 必备字段 |
| --- | --- |
| 自选空 | 标题「还没有自选标的」、说明、2 个动作 |
| 搜索空 | 查询词、0 结果说明、2 个动作 |
| 指标空 | 查询词、0 结果、查看全部动作 |
| 数据不足 | 指标名、需要根数 N、当前根数 M、口径入口 |
| 分组空 | 分组名、说明「这个分组还没有标的」、去行情动作 |

**边界与异常**：
- 空态与错误态区分：数据缺失/损坏是错误，不是空态。
- 空态下快捷入口不可用：按钮禁用并说明，不跳到空白页。
- 数据不足时用户关闭提示（F-06.02）：仍无曲线，图例「—」，不出现空白无解释。

**验收标准**：
- AC-08.01-01 Given 自选为空（含「未分组」视图为空），Then 显示「还没有自选标的」、说明与「去行情挑选」「搜索标的」两个动作；刷新不出现骨架屏。
- AC-08.01-02 Given 搜索无结果，Then 查询词保留，显示「未找到」与「清空」「去行情浏览」；不自动清空、不返回无关结果。
- AC-08.01-03 Given 指标搜索无结果，Then 显示「0 个匹配」与「查看全部指标」，查询词保留。
- AC-08.01-04 Given 指标预热不足，Then 面板显示「需要 N 根，当前 M 根」与口径入口；不画线、不画 0。
- AC-08.01-04（补5） Given 自选总数 >0 但某分组为 0，Then 显示「这个分组还没有标的」+「去行情页加星」，组名「未分组」不带括号，组头与左栏计数 0 保留，不回落成「还没有自选标的」。
- AC-08.01-05 Given 任意空态，Then 至少有一个可执行的下一步动作；不存在只有「暂无数据」四个字、无动作的页面。

**Story**：S-08.01-01、S-08.01-02、S-08.01-03

#### F-08.02 错误态（P0）

**目标用户与场景**：参数输错、数据损坏、未来真实源超时、零成交量指标无定义时，用户需要知道错误类型、能否恢复、如何恢复，并且不能丢失已有图表。

**功能描述**：统一错误卡组件：错误码、错误类、用户可读说明、trace id、动作按钮。四类错误：可纠正、可重试、不可恢复、可解释。MVP 必须覆盖参数越界、上游超时（故障注入）、数据集损坏、零量无定义。

**交互与状态定义**：
- 可纠正（参数越界）：字段级红框 + 行内提示，不弹全屏错误；不发起计算；「恢复默认」。
- 可重试（上游超时）：保留当前图表；只重试失败批次；显示 `retry_after`；自动重试最多 3 次（1s/3s/5s），仍失败转手动；不整页刷新。
- 不可恢复（数据集损坏）：阻断行情/工作台；显示期望/实际 sha256、trace；动作「重建样本包」「导出诊断」「以只读方式查看」（无有效快照时只读不可用）。
- 可解释（零成交量无定义）：不弹 toast；指标面板内联标注「停牌无定义」，线断开；动作「更换指标」「查看口径」。
- 错误卡不可只显示「出错了」；不得显示堆栈给普通用户；日志保留完整堆栈。
- 状态：错误发生、重试中、已恢复、只读。

**错误码与分类**：
| 错误码 | 类 | 触发 | UI | 恢复 |
| --- | --- | --- | --- | --- |
| `E_PARAM_OUT_OF_RANGE` | 可纠正 | 参数越界 | 字段红框 + 范围 | 恢复默认/修正 |
| `E_UPSTREAM_TIMEOUT` | 可重试 | 数据批次超时（故障注入） | 局部错误条 + retry_after | 重试缺失批次 |
| `E_DATASET_CORRUPT` | 不可恢复 | sha256/解析失败 | 全屏错误卡 | 重建/诊断/只读 |
| `E_UNDEFINED_ZERO_VOLUME` | 可解释 | 零量导致除零 | 面板内联标注 | 换指标/看口径 |
| `E_SPEC_MISSING` | 不可恢复 | 指标缺口径页 | 目录行错误 + 禁止加入 | 联系支持/等待修复 |
| `E_PROVENANCE_MISSING` | 可解释 | 溯源字段缺失 | 溯源卡标「缺失」 | 导出诊断 |
| `E_STATE_DB_WRITE` | 可重试 | 设置/自选写入失败 | toast + 重试 | 重试写入 |

**边界与异常**：
- 错误发生时已有曲线：保留，不白屏；标注「计算失败/数据过期」。
- 重试不可用（不可恢复）：按钮禁用或隐藏，不能出现点了没反应的死按钮。
- 同一错误重复出现：合并为一条，不堆叠 toast。
- 只读模式：禁用写入与重建，仍可看图/查口径；顶部常驻「只读」标识。

**验收标准**：
- AC-08.02-01 Given 参数输入 260（上限 200），Then 字段红框显示范围、错误码与 trace；不发起 IPC；恢复默认后回到 14，无需刷新。
- AC-08.02-02 Given 上游超时（故障注入），Then 保留当前图表，仅重试失败批次，显示 retry_after；最多自动重试 3 次后转手动，不整页刷新。
- AC-08.02-03 Given 数据集 sha256 不一致，Then 阻断加载，显示期望/实际摘要与 trace id，提供重建/诊断/只读；不渲染任何行情行。
- AC-08.02-04 Given 零成交量导致 MFI 无定义，Then 面板内联显示「停牌无定义」，线断开，图例「—」；不弹全屏错误、不显示 0。
- AC-08.02-05 Given 任意错误卡，Then 必含错误类、错误码、trace id 与至少一个动作；不可重试错误不得显示可点击的重试按钮。

**Story**：S-08.02-01、S-08.02-02、S-08.02-03、S-08.02-04

## 5. 边界与非目标

### 5.1 MVP 非目标清单与理由

| # | 不做 | 理由 | 对 MVP 的影响 |
| --- | --- | --- | --- |
| N-01 | 实时行情、分时、分钟线、逐笔、Level-2 | 产品定位是盘后复盘；实时数据成本、授权与引擎复杂度远超 MVP；D-03 已冻结日线最小周期 | 所有页面只展示日线及周/月聚合；不出现「实时」字样 |
| N-02 | Windows / Linux / 移动端 / Web 版 | 首发聚焦 macOS，减少打包、签名、快捷键与窗口管理分叉（D-11） | 仅提供 macOS dmg；关于页只列 macOS |
| N-03 | 账户、登录、支付、订阅、云同步、云控制面 | MVP 免费、本地优先；避免引入服务端与隐私合规面（D-10） | 无登录页、无付费墙、无云备份；换机需重建样本 |
| N-04 | 启用真实数据源、tushare token、实际回填、多源 fallback/跨源拼接 | 真实源接入约 8.5 人周；MVP 用 Mock 验证产品与引擎；tushare 只留骨架（D-04） | 数据源页 tushare 永久置灰；回填卡只展示不执行 |
| N-05 | 荐股、买卖信号、收益预测、回测、组合推荐 | 合规与产品定位：分析工具而非投资建议（D-12） | 无「买入/卖出」按钮；指标只呈现读数与口径 |
| N-06 | 画图工具（趋势线、水平线、通道、斐波那契） | 架构报告 B6 标「可延后」；画线需要锚点持久化、复权平移与命中测试，成本高；与 `最小MVP.md` 的「必须做」冲突，见 C-01 与 Q-02 | v0.1 图表只做缩放/平移/十字光标；无画线工具栏 |
| N-07 | 指标组合保存、分享、导入导出 | 需要额外的组合 schema、冲突合并与 UI；架构估算约 1 人周；P1 更合适 | 指标实例只在当前会话保留；重启回默认 |
| N-08 | 自定义指标、脚本、公式编辑器 | 引入沙箱、安全、校验与支持成本；105 个内置指标已覆盖 MVP 需求 | 参数可改，公式只读；口径页只读 |
| N-09 | 财务数据、公告、新闻、龙虎榜、个股资金流独立页 | MVP 数据源不提供这些数据；加入会稀释「指标工作台」定位 | 仅有量价派生指标，无基本面/消息面 |
| N-10 | 持仓组合、交易记录、收益统计、券商接入 | 只有 P1 的「每股成本/浮盈亏率」；组合与交易涉及对账、精度与合规 | 自选不等于持仓；不计算总资产 |
